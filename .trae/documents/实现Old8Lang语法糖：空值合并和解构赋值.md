# 实现Old8Lang语法糖：空值合并和解构赋值

## 1. 实现空值合并运算符 (`??`)

### 1.1 添加标记类型
在`LangTokenType`枚举中添加`NullishCoalescing`标记类型，用于表示`??`运算符。

### 1.2 更新词法分析器
在`LangTokenizer.Tokenize`方法中添加对`??`运算符的识别：
```csharp
if (code[i] == '?' && i + 1 < code.Length && code[i + 1] == '?')
{
    tokens.Add(new LangToken("??", LangTokenType.NullishCoalescing, line, i - column));
    i++;
    continue;
}
```

### 1.3 添加语法解析支持
在`ExpressionParser`类中添加对空值合并运算符的解析，需要确定其优先级（通常低于逻辑运算符，高于条件运算符）。

### 1.4 实现解释和编译支持
- 在解释器中实现`??`运算符的逻辑：如果左侧值为null，则返回右侧值，否则返回左侧值
- 在编译器中添加对`??`运算符的IL生成支持

## 2. 实现解构赋值

### 2.1 添加数组解构支持
- 在`StatementParser.ParseSet`方法中添加对数组解构语法的识别：`[a, b] <- [1, 2]`
- 实现数组解构的解析逻辑，将解构模式转换为多个赋值语句

### 2.2 添加对象解构支持
- 在`StatementParser.ParseSet`方法中添加对对象解构语法的识别：`{name, age} <- person`
- 实现对象解构的解析逻辑，将解构模式转换为多个赋值语句

### 2.3 实现解构赋值的执行逻辑
- 在解释器中实现解构赋值的执行逻辑：
  - 对于数组解构，根据索引将值赋给对应的变量
  - 对于对象解构，根据属性名将值赋给对应的变量
- 在编译器中添加对解构赋值的IL生成支持

## 5. 预期效果

实现后，Old8Lang将支持以下语法：

```old8
// 空值合并
result <- value ?? defaultValue

// 数组解构赋值
[a, b] <- [1, 2]

// 对象解构赋值
{name, age} <- person
```

这些语法糖将使Old8Lang的代码更加简洁和易读，提高开发效率。
