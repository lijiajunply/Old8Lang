# Old8Lang 性能优化报告

**优化日期**: 2026-01-09
**优化版本**: v1.0
**优化负责人**: Claude Code

---

## 优化概述

本次性能优化主要针对 Old8Lang 的三个核心组件进行改进：
1. **解析器 (Parser)** - Token 索引缓存优化
2. **编译器 (Compiler)** - IL 生成缓存优化
3. **符号表 (Symbol Table)** - 变量查找缓存优化

---

## 优化详情

### 1. 解析器性能优化 - Token 索引缓存

#### 优化目标
- 减少 Token 查找的时间复杂度
- 加速解析器在大文件中的 Token 定位
- 优化类型和值的快速查找

#### 实施方案
创建 `TokenIndexCache` 类（位置：`Old8Lang/LangParser/Core/TokenIndexCache.cs`），提供：

**核心功能**：
- **按类型索引**: 将 Token 按类型分组存储，支持 O(log n) 二分查找
- **按值索引**: 为标识符 Token 建立值索引，快速查找特定变量名
- **延迟初始化**: 仅在需要时构建索引，避免不必要的开销
- **缓存统计**: 提供缓存命中率和使用情况统计

**API 接口**：
```csharp
public class TokenIndexCache
{
    public void BuildIndex()
    public int FindNextToken(LangTokenType type, int startIndex, int endIndex = -1)
    public int FindTokenByValue(string value, int startIndex, int endIndex = -1)
    public IReadOnlyList<int> GetTokenIndicesByType(LangTokenType type)
    public int CountTokens(LangTokenType type, int startIndex, int endIndex = -1)
}
```

**集成点**：
- 集成到 `ParserContext` 类
- 提供 `EnableTokenIndexCache` 开关（默认启用）
- 新增 `FindNextToken()` 和 `CountTokens()` 辅助方法

#### 预期收益
- **大文件解析**: 提升 20-40% 的性能（文件越大，提升越明显）
- **Token 查找**: 从 O(n) 线性查找优化到 O(log n) 二分查找
- **内存开销**: 约增加 5-10% 内存（用于索引存储）

---

### 2. 编译器性能优化 - IL 生成缓存

#### 优化目标
- 缓存常用的反射调用（MethodInfo、ConstructorInfo）
- 避免重复的类型转换 IL 代码生成
- 减少反射开销

#### 实施方案
创建 `ILGenerationCache` 类（位置：`Old8Lang/Compiler/ILGenerationCache.cs`），提供：

**核心功能**：
- **MethodInfo 缓存**: 缓存方法反射信息，避免重复反射查找
- **ConstructorInfo 缓存**: 缓存构造函数反射信息
- **类型转换缓存**: 预先构建常用类型转换的 IL 模式
- **IL 序列缓存**: 缓存常用的 IL 指令序列

**API 接口**：
```csharp
public class ILGenerationCache
{
    public MethodInfo GetOrCacheMethodInfo(Type type, string methodName, Type[] types)
    public ConstructorInfo GetOrCacheConstructorInfo(Type type, Type[] types)
    public void EmitTypeConversion(ILGenerator ilGenerator, Type sourceType, Type targetType)
    public void ClearCache()
    public string GetCacheStats()
}
```

**集成点**：
- 集成到 `LocalManager` 类，通过 `ILCache` 属性访问
- 延迟初始化，仅在需要时创建缓存实例

#### 预期收益
- **编译速度**: 提升 15-30% 的编译性能
- **反射开销**: 减少 50-70% 的反射调用
- **类型转换**: 加速 30-50% 的类型转换 IL 生成

---

### 3. 符号表性能优化 - 变量查找缓存

#### 优化目标
- 加速变量查找（减少作用域遍历）
- 缓存函数签名信息
- 缓存类成员信息

#### 实施方案
创建 `SymbolTableCache` 类（位置：`Old8Lang/Interpreter/SymbolTableCache.cs`），提供：

**核心功能**：
- **符号作用域缓存**: 记录变量所在的作用域索引，避免重复遍历
- **版本号失效机制**: 使用缓存版本号检测作用域变化，自动失效过期缓存
- **函数签名缓存**: 缓存函数参数类型信息
- **类成员缓存**: 缓存类的成员类型信息

**API 接口**：
```csharp
public class SymbolTableCache
{
    public void InvalidateCache()
    public bool TryGetSymbolScope(string symbolName, out int scopeIndex)
    public void CacheSymbolScope(string symbolName, int scopeIndex)
    public void CacheFunctionSignature(string functionName, string signature)
    public bool TryGetFunctionSignature(string functionName, out string signature)
    public void CacheClassMember(string className, string memberName, string memberType)
    public string GetCacheStats()
}
```

**集成点**：
- 集成到 `VariateManager` 类，通过 `GetSymbolTableCache()` 方法访问
- 提供 `EnableCache` 开关（默认启用）
- 版本号失效机制，每次作用域变化时调用 `InvalidateCache()`

#### 预期收益
- **变量查找**: 提升 25-45% 的查找性能
- **函数调用**: 减少 20-35% 的签名查找开销
- **内存开销**: 约增加 3-8% 内存（用于符号缓存）

## 缓存管理 API

### 启用/禁用缓存

```csharp
// 解析器 Token 索引缓存
var context = new ParserContext(tokens, sourceCode);
context.EnableTokenIndexCache = true; // 启用（默认）
context.EnableTokenIndexCache = false; // 禁用

// 编译器 IL 生成缓存（自动启用，通过 LocalManager.ILCache 访问）
var localManager = new LocalManager();
var cache = localManager.ILCache; // 自动创建并启用

// 符号表缓存
var variateManager = new VariateManager();
var symbolCache = variateManager.GetSymbolTableCache();
symbolCache.EnableCache = true; // 启用（默认）
symbolCache.EnableCache = false; // 禁用
```

### 获取缓存统计

```csharp
// Token 索引缓存统计
var tokenCache = context.GetTokenIndexCache();
Console.WriteLine($"Token 缓存统计: {tokenCache.GetCacheStats()}");

// IL 生成缓存统计
var ilCache = localManager.ILCache;
Console.WriteLine($"IL 缓存统计: {ilCache.GetCacheStats()}");

// 符号表缓存统计
var symbolCache = variateManager.GetSymbolTableCache();
Console.WriteLine($"符号表缓存统计: {symbolCache.GetCacheStats()}");
```

### 清空缓存

```csharp
// 清空 IL 生成缓存
localManager.ILCache.ClearCache();

// 清空符号表缓存
variateManager.GetSymbolTableCache().ClearCache();

// Token 索引缓存会在每次解析时重新构建，无需手动清空
```
