# 阶段 3.12 IL 编译器驱动迁入 IL 后端

日期：2026-11-14 17:40  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3 的 IL 引擎余量。

## 改动

1. `Old8Lang.Runtime/Compiler/Compiler.cs`、`GlobalVariableAnalysis.cs`、
   `Verification/ILVerifier.cs` 迁入 `Old8Lang.Compiler`，命名空间不变。
2. Runtime 新增共享开关 `IlCompilerOptions`：
   - `DebugOutputEnabled`、`IlVerificationEnabled`、`EnableAsyncStateMachineAwait`；
   - `ApplyHeaderDirectives`：处理 `debug`/`verify-il`/`type-inference`/`type-inference-debug`。
   `Old8Lang.Compiler.Compiler` 的同名属性委托到该选项类型，App/Tests 的既有 API 保持不变。
3. Runtime 的 `AsyncFuncLangValue` 与 `AsyncStateMachineGenerator` 改用 `IlCompilerOptions`，
   不再引用 `Old8Lang.Compiler.Compiler`；`LangInterpreter` 的文件头指令也改为调用共享选项。
4. `GlobalVariableScope` 是 `LocalManager` 的共享类型，从 `GlobalVariableAnalysis.cs` 拆到
   Runtime 的 `Compiler/CodeGeneration/GlobalVariableScope.cs`；分析器本身随驱动迁出。
5. Runtime 的 `Compiler/` 目录现在只剩共享编译契约：
   `LocalManager`、IL 生成缓存、`GlobalVariableScope`、`RuntimeGlobals`/常量注册表、
   `AssertHelper`/`ExceptionWrapper`、泛型特化、`IlDisassembler`（异步函数调试输出仍使用）。
