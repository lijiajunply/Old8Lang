### 主要问题分析

#### 1. 语法错误问题
**错误类型**: `SyntaxError - 缺少逗号 ','`
**影响测试**: 变量作用域测试、跳转语句测试中的多个用例
**问题描述**: 在 `for` 循环语法解析时，解析器期望逗号但遇到分号
**示例**:
```old8
for i <- 0; i < 5; i <- i + 1 {
    temp <- i * 2  // 解析器在这里报错
    sum <- sum + temp
}
```
**根本原因**: `for` 循环内的变量声明被误认为是元组或列表语法

#### 2. Assert静态类调用问题
**错误类型**: `InvalidOperationError - 方法 'True' 未找到`
**影响测试**: 所有使用 `Assert.True()` 的测试用例
**问题描述**: 编译器无法找到 `Assert` 静态类的 `True` 方法
**示例**:
```old8
Assert.True(test() == 42)
// 错误: 方法 'True' 未找到
```
**根本原因**:
1. Assert 静态类可能未正确注册到编译器上下文
2. 静态类的方法查找机制在编译模式下可能存在问题

#### 3. 类型兼容性问题
**错误类型**: `CompilerException - 类型不兼容`
**影响测试**: 变量作用域相关测试
**问题描述**: 编译器检测到类型不匹配（预期 Int32, 实际 String）
**示例**:
```old8
x <- 10
x <- "hello"  // 动态类型重新赋值
x <- true
```
**根本原因**: 编译模式下的类型检查比解释模式更严格，但测试用例是基于动态类型设计的

#### 4. Void函数返回问题
**错误类型**: `InvalidProgramException`
**影响测试**: `Return_VoidFunction_ReturnsNothing` 测试
**问题描述**: void 函数的 IL 生成存在问题
**示例**:
```old8
func voidFunc() -> void {
    x <- 10
    return
}
```
**根本原因**: Void 函数的 return 语句 IL 生成不正确
