# IL 具名函数读取顶层变量测试报告

- 日期：2026-11-11 22:40
- 范围：IL 模式（`-il`）顶层变量作用域模型
- 结论：通过。具名函数、lambda、类方法和字段初始化器均可读写顶层变量；无新增回归。

## 1. 问题与根因

原复现：

```old8
g <- 10
func f() -> int { return g + 1 }
PrintLine(f())
```

`-il` 下编译期报 `变量 'g' 未声明`。

根因：顶层变量是 `OldLangRun` 动态方法的局部变量（`LocalBuilder`），具名函数被编译成另一个
`DynamicMethod`。函数体的 `LocalManager` 是一份新实例，既看不到顶层局部变量，也不能把
`OldLangRun` 的 `LocalBuilder` 直接拿来用。lambda 的闭包数组模型只适合「创建点可见的局部变量」，
不能表达函数与顶层变量之间的共享读写。

## 2. 实现方案

1. **编译前分析**（`GlobalVariableAnalysis`）
   - 收集直接位于顶层作用域的赋值目标；`if` / `for` / `while` / `try` 块在解释器中是子作用域，
     其中首次赋值的变量不算顶层变量。
   - 通过 AST 遍历收集所有会在独立方法中执行的代码里的标识符：具名函数 / lambda（含参数默认值）、
     类定义（字段初始化器与方法体）。
   - 被引用的顶层变量被提升为「全局槽位」；其余顶层变量继续使用普通局部变量，避免影响循环性能。
   - 推断槽位静态类型；对函数返回值初始化、前向引用做多轮迭代。
2. **运行期共享环境**（`RuntimeGlobals`）
   - 使用 `[ThreadStatic]` 存储名称 → 值槽位，编译产物每次执行前由包装委托重置。
   - 顶层与函数体都通过 `RuntimeGlobals.Get/Set` 读写同一槽位；未赋值时读取按「变量未声明」抛出
     `NAME_ERROR`，与解释器一致。
   - 执行结束后把已赋值的槽位写回 `VariateManager`，宿主可读取函数修改后的最终值。
3. **遮蔽顺序**
   - 参数、局部变量、闭包单元、字段优先于全局槽位；函数参数与顶层变量同名时不会污染顶层变量。
   - 顶层 C 风格 `for` 的循环变量与已提升的顶层变量同名时，在循环内建立局部遮蔽（初始化表达式
     仍先按全局值求值），循环结束后恢复槽位读取，避免循环变量写坏顶层变量。
4. **作用域传播**
   - `LocalManager` 增加 `Globals`（共享分析结果）与 `IsTopLevelScope`。
   - 函数、lambda、类方法、泛型特化、字段初始化器的 `LocalManager` 均继承 `Globals`。

### 3.4 跨模式手工对比（`-f` / `-il` 输出一致）

- 前向引用、字符串 / double / bool 读写、多个函数共享、递归函数修改全局。
- 顶层 lambda 写回全局；lambda 在创建后能看到顶层变量的后续赋值；具名函数内创建并返回读取顶层变量的闭包。
- 类方法读写全局、类字段初始化器读取全局。
- 列表 / 字典全局的读取与原地修改（`items[0] <- ...`）。
- 函数内同名参数 / 局部变量遮蔽全局变量。
- `i <- 100` + 函数读取 `i` + `for i <- 0, i < 3, i++`：两模式函数均读到 `100`，循环变量不写回顶层变量。
- 读取尚未赋值的全局：解释器与 IL 均报名称错误。
- `TestFiles/CompilerTests/closure_global_test.old8`、`closure_test.old8` 在 `-il` 下通过。

## 4. 已知限制与顺带发现

1. 异步函数尚未接入全局槽位模型（`AsyncStateMachineGenerator` 的变量提升路径未处理）。
2. 槽位环境是线程静态的；编译产物内部再跨线程调用函数时读不到顶层变量。
3. 解构赋值（`[a, b] <- ...`、`(a, b) <- ...`）的目标变量未纳入顶层变量分析；函数引用它们时仍按原逻辑报未声明。
3. 顺带发现且未修改（已记入 `Todo.md`）：
   - IL 实例方法读取裸字段（`return field`）运行期 `NullReferenceException`，`this.field` 正常。
   - IL 中 `items.Length > 0` 会生成无效 IL / 运行期 NRE，单独 `items.Length` 正常。
