## 实现细节

### 生成器语法设计
```
# 生成器函数声明
func generator() {
    yield 1
    yield 2
    yield 3
}

# 生成器调用和遍历
for item in generator() {
    PrintLine(item)
}
```

### 生成器实现原理
1. 生成器函数执行时，返回一个 `GeneratorLangValue` 对象
2. 每次调用生成器的迭代方法，函数执行到下一个 `yield` 语句
3. `yield` 语句暂停函数执行，并将值返回给调用者
4. 再次调用迭代方法时，函数从上次暂停的位置继续执行
5. 函数执行完毕后，生成器标记为已完成

### GeneratorLangValue 设计
- 保存生成器函数的引用
- 保存生成器的当前状态（执行位置、局部变量等）
- 实现迭代器协议，支持 `next()` 方法
- 支持生成器的重置和关闭

### 关键技术点
- 函数状态保存与恢复机制
- 迭代器协议实现
- 状态机设计（编译模式）
- 闭包与生成器的交互
- GeneratorLangValue 与现有类型系统的集成
