## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `ForInStatement` | 从 Runtime 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| 执行辅助 | `RunStandard`、`RunWithGeneratorContext`、异步生成器/异步流/生成器分支移入 `ForInStatementRuntimeExtensions`；两个 partial 合并为 `partial static class` |
| 编译辅助 | `GenerateDictionaryIl` 移入同一扩展类的编译 partial 文件 |
| 字段访问 | Visitor 改用公开 `Ids`（原 `AllIds` 内部属性不再跨程序集）；扩展类内部统一使用 `node.Id`/`node.Expression`/`node.Body`/`node.Position` |
| 生成代码 | `IVisitor` 新增 `VisitForInStatement`；Runtime 节点 63 → 62；旧 Accept 文件归档 |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 17 → 15 |

行为保持：集合/字典/生成器/异步生成器/异步流的遍历分支、key-value 解构、break/continue/yield
处理、生成器缓存恢复与 IL 字典遍历生成均按原实现逐行迁移。
