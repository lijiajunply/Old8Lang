# 修复函数重载检查逻辑

## 问题分析

测试失败的主要原因是函数重载检查逻辑存在缺陷：
- 在 `FuncInit.cs` 的 `Run` 方法中，检查函数是否重复的逻辑只比较了**函数名**和**参数数量**
- 没有比较**参数类型**，导致即使参数类型不同，同名同参数数量的函数也被视为重复
- 这违反了函数重载的基本规则：函数名相同但参数类型不同的函数应该被允许共存

## 修复计划

### 1. 修改 `FuncInit.cs` 中的重复函数检查逻辑

**文件：** `/Users/luckyfish/Documents/Project/RiderProjects/Old8Lang/Old8Lang/AST/Statement/FuncInit.cs`

**修改内容：**
- 在第 38-41 行的重复函数检查中，添加参数类型比较
- 对于每个参数，比较其类型注解（AssumptionType）
- 只有当函数名、参数数量**和**所有参数类型都相同时，才视为重复函数

## 修复代码示例

### FuncInit.cs 修复示例
```csharp
// 修改前
var existingFunc = manager.ImportInfos.FirstOrDefault(info =>
    info is FuncLangValue func &&
    func.Id?.IdName == FuncLangValue.Id.IdName &&
    func.Ids?.Count == FuncLangValue.Ids?.Count);

// 修改后
var existingFunc = manager.ImportInfos.FirstOrDefault(info =>
    info is FuncLangValue func &&
    func.Id?.IdName == FuncLangValue.Id.IdName &&
    func.Ids?.Count == FuncLangValue.Ids?.Count &&
    func.Ids?.Zip(FuncLangValue.Ids!, (a, b) => a.AssumptionType == b.AssumptionType).All(x => x) == true);
```

这个修复将确保只有当函数名、参数数量**和**所有参数类型都完全匹配时，才会被视为重复函数，从而正确支持函数重载。
