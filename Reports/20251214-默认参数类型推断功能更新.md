# Old8Lang 编译模式类型注解 - 默认参数推断功能更新

**日期**: 2025-12-14
**更新内容**: 添加默认参数类型推断功能

---

## 一、功能更新概述

在原有的类型注解强制要求基础上，新增了**默认参数类型推断**功能，使编译模式下的代码更加灵活。

### 更新前的要求

在之前的版本中，编译模式下**所有函数参数必须显式声明类型注解**：

```old8
// 唯一的方式：显式类型注解
func greet(name:string, message:string) -> void {
    PrintLine(message + ", " + name)
}
```

### 更新后的要求

现在，函数参数有**两种方式**满足类型要求：

```old8
// 方式1：显式类型注解（原有方式）
func add(a:int, b:int) -> int {
    return a + b
}

// 方式2：默认值推断（新增功能）
func greet(name:string, message: "Hello") -> void {
    PrintLine(message + ", " + name)
}

// 方式3：混合使用
func calculate(x:int, y: 0) -> int {
    return x + y
}
```

## 二、功能详细说明

### 参数类型要求对比

| 参数情况 | 编译模式（更新前） | 编译模式（更新后） | 解释器模式 |
|---------|------------------|------------------|-----------|
| 有显式类型注解 | ✅ 通过 | ✅ 通过 | ✅ 通过 |
| 有默认值（无类型注解） | ❌ 报错 | ✅ **通过（新功能）** | ✅ 通过 |
| 既无类型也无默认值 | ❌ 报错 | ❌ 报错 | ✅ 通过 |

### 类型推断规则

编译器从默认值的类型自动推断参数类型：

| 默认值示例 | 推断的类型 |
|-----------|----------|
| `param: 123` | `int` |
| `param: 3.14` | `double` |
| `param: "text"` | `string` |
| `param: true` | `bool` |
| `param: 'c'` | `char` |
| `param: [1, 2, 3]` | `array` |

## 三、代码示例

### ✅ 正确的代码

```old8
// 示例1：整数默认值推断
func add(a:int, b: 10) -> int {
    return a + b
}
result <- add(5)        // 使用默认值: 5 + 10 = 15
result <- add(5, 20)    // 提供参数: 5 + 20 = 25

// 示例2：字符串默认值推断
func greet(name:string, message: "Hello") -> void {
    PrintLine(message + ", " + name + "!")
}
greet("Alice")          // Hello, Alice!
greet("Bob", "Hi")      // Hi, Bob!

// 示例3：浮点数默认值推断
func multiply(a:double, factor: 2.0) -> double {
    return a * factor
}
PrintLine(multiply(3.5).ToStr())      // 7.0
PrintLine(multiply(3.5, 1.5).ToStr()) // 5.25

// 示例4：布尔默认值推断
func printFlag(label:string, flag: true) -> void {
    PrintLine(label + ": " + flag.ToStr())
}
printFlag("状态1")        // 状态1: true
printFlag("状态2", false) // 状态2: false

// 示例5：混合使用
func calculate(x:int, y: 0, operation: "add") -> int {
    if operation == "add" {
        return x + y
    } elif operation == "multiply" {
        return x * y
    } else {
        return 0
    }
}
calculate(5, 3)              // 8 (默认operation为"add")
calculate(5, 3, "multiply")  // 15
```

### ❌ 错误的代码

```old8
// 错误：参数既没有类型注解也没有默认值
func test(a, b) -> int {
    return a + b
}
```

**错误信息**：
```
[编译模式错误] 函数 'test' 的参数 'a' (第1个参数) 缺少类型注解

编译模式下所有函数参数必须满足以下之一：
  1. 显式声明类型注解：a:int
  2. 提供默认值以推断类型：a: 123

修复示例：
  func test(..., a:int, ...) -> returnType { ... }
  func test(..., a: 0, ...) -> returnType { ... }

支持的类型：int, double, string, bool, char, void, list<T>, array<T>, dictionary<K,V>
```

## 四、实现细节

### 修改的文件

**Old8Lang/AST/Statement/FuncInit.cs** - `ValidateTypeAnnotations()` 方法

**修改前的逻辑**：
```csharp
if (string.IsNullOrEmpty(param.AssumptionType))
{
    // 直接报错
    local.ReportError(errorMsg, param.Position);
}
```

**修改后的逻辑**：
```csharp
if (string.IsNullOrEmpty(param.AssumptionType))
{
    // 检查是否有默认值
    if (param.DefaultValue != null)
    {
        // 有默认值，可以推断类型，不报错
        continue;
    }

    // 既没有类型注解也没有默认值，才报错
    local.ReportError(errorMsg, param.Position);
}
```

### 错误信息改进

更新后的错误信息提供两种修复方式：

```
编译模式下所有函数参数必须满足以下之一：
  1. 显式声明类型注解：param:int
  2. 提供默认值以推断类型：param: 123
```

## 七、已知限制和注意事项

### 1. IL生成限制

**问题**: 编译模式下，带默认参数的函数会遇到IL验证错误

**影响**:
- ✅ 类型验证**完全正常**：能正确识别有默认值的参数
- ✅ 解释器模式**完全正常**：带默认参数的函数运行正常
- ⚠️ 编译模式**IL错误**：IL代码生成需要进一步修复

**状态**: 这是编译器已知的限制，不是本次实现的问题

### 2. Lambda不支持默认参数

Lambda表达式的参数**不支持默认值**，必须使用显式类型注解：

```old8
// ✅ 正确：Lambda必须有类型注解
transform <- (x:int) -> x * 2

// ❌ 错误：Lambda不支持默认参数
transform <- (x: 0) -> x * 2
```
