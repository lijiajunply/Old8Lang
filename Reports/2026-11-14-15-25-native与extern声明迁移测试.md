# 阶段 2「native / extern 声明迁移」测试报告

日期：2026-11-14 15:25
范围：`Docs/architecture-migration/plan.md` §2 的增量：`NativeStatement`、`ExternStatement` 及 extern 声明模型
状态：本批完成；阶段 2 整体未完成（`ImportStatement`、`Instance`、`LinqExpression`、解析器整体仍待拆分）。

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `NativeStatement`（Syntax） | 函数签名由 `FuncLangValue?` 改为 `FunctionSyntax?`；构造签名同步调整；`ToString` 使用语法模型 |
| `ExternStatement` + `ExternFunctionDeclaration` + `CSharpDllImportDeclaration`（Syntax） | 整体迁入 Syntax；内部字段改为公开只读属性 `DllName`/`Functions`/`DefaultCallingConvention`/`ExternType`；签名格式化直接读 `FunctionSyntax` |
| 运行时适配 | `NativeStatement.GetFuncValue()` 按需创建/缓存运行时签名；Native 执行路径改用该入口 |
| 解析器 | `StatementParser.ImportAndNative` 与 `ExternStatement` 构造点保持不变（构造参数已为语法类型） |
| 消费者更新 | Interpreter/Compiler 的 extern/native 分支、块声明分类、测试与 Visitor 桩同步更新 |
| 生成代码 | Runtime 节点 53 → 51；遗留 partial 保持 8 |

行为保持：extern 类型探测、P/Invoke/Python/JS/C# 提供器分派、native 方法/类导入别名与签名显示均未改动。
