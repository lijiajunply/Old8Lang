# 阶段 2「switch / try 节点迁移」测试报告

日期：2026-11-14 14:30
范围：`Docs/architecture-migration/plan.md` §2 的增量：`SwitchStatement`、`CaseStatement`、`TryStatement`
状态：本批完成；阶段 2 整体未完成（函数/类声明、for-in、解析器、运行时值仍待拆分）。

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `SwitchStatement`、`CaseStatement`、`TryStatement` | 从 Runtime 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| Visitor 分派 | `IVisitor` 新增 `VisitSwitchStatement`、`VisitCaseStatement`、`VisitTryStatement`；重新生成后 Runtime 节点 65 |
| 编译辅助 | `TryGenerateIntSwitch` 移入 `SwitchStatementRuntimeExtensions`；try 的 `RunWithGeneratorContext`/`RunStandard`/`IsMatch` 移入 `TryStatementRuntimeExtensions` |
| 可见性调整 | `SwitchStatement` 的 `SwitchExpression`/`SwitchCaseList`/`DefaultBlockStatement` 由 internal 改为公开只读属性（Visitor 与扩展类跨程序集访问） |
| 生成代码 | 三个旧 `*.Accept.generated.cs` 归档到 `backups/trash-2026-11-14/` |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 20 → 18 |

行为保持：switch 的解释顺序、整数跳转表优化条件、case 标签与 default 回退；try 的
`/try`、`/catch` 生成器路径、catch 过滤器与变量绑定、未匹配异常重抛、finally 执行顺序均未改动。
