## 功能特性

### 联合类型 (A | B)

**语义**：值可以是类型 A 或类型 B
**用途**：编译时类型检查（类似 TypeScript）

**支持的场景**：
- 变量声明：`a: int | string <- 123`
- 函数参数：`func process(x: int | string) -> void`
- 函数返回值：`func getValue() -> int | string`
- 类字段：`public data: int | string | bool`
- 泛型参数：`List<int | string>`
- 可空联合类型：`value: int? | string? <- null`

**兼容性规则**：
- `A | B` 兼容于 `A`（联合类型可以赋值给任一成员类型）
- `A` 兼容于 `A | B`（任一成员类型可以赋值给联合类型）
- `null` 兼容于任何包含可空类型的联合类型

### 交叉类型 (A & B)

**语义**：类型必须同时满足 A 和 B 的约束
**用途**：主要用于接口/约束组合

**支持的场景**：
- 泛型约束：`where T: IComparable & ICloneable`
- 函数参数：`func process(x: A & B) -> void`
- 变量声明：`value: Interface1 & Interface2`

**兼容性规则**：
- `A & B` 兼容于 `A`（交叉类型满足所有成员）
- `A & B` 兼容于 `B`
- `A` 不兼容于 `A & B`（单个类型不满足所有约束）

### 2. LangParser/Parsers/FunctionParser.cs

1. 添加 `ParseComplexTypeAnnotation()` 公共方法，处理联合/交叉类型注解：
   ```csharp
   public string ParseComplexTypeAnnotation()
   {
       var result = "";
       while (true)
       {
           // 处理终止符：<-, ,, ), }, where, {, ;, EOF
           if (CurrentToken.Type is LangTokenType.Assignment ...)
           {
               break;
           }

           if (CurrentToken.Type == LangTokenType.Identifier)
           {
               result += CurrentToken.Value;
               Expect(LangTokenType.Identifier);

               // 处理泛型和可空类型
               if (CurrentToken.Type == LangTokenType.LessThan)
               {
                   result += ParseGenericTypeAnnotation();
               }

               if (CurrentToken.Type == LangTokenType.Question)
               {
                   result += "?";
                   Expect(LangTokenType.Question);
               }
           }
           else if (CurrentToken.Type == LangTokenType.Pipe)
           {
               result += "|";
               Expect(LangTokenType.Pipe);
           }
           else if (CurrentToken.Type == LangTokenType.Ampersand)
           {
               result += "&";
               Expect(LangTokenType.Ampersand);
           }
           else
           {
               break;
           }
       }
       return result.Trim();
   }
   ```

## 技术细节

### 解析优先级

按照以下顺序解析类型注解：
1. 可空标记 `?`
2. 联合类型 `|`
3. 交叉类型 `&`
4. 泛型 `<>`

### 终止符处理

`ParseComplexTypeAnnotation()` 在遇到以下符号时停止解析：
- `<-` (Assignment)
- `,` (Comma)
- `)` (RightParen)
- `}` (RightBrace)
- `where` (Where)
- `{` (LeftBrace)
- `;` (Semicolon)
- EOF (EndOfFile)

### 递归解析

- 联合类型和交叉类型都支持递归解析
- 每个成员类型可以是：
  - 简单类型：`int`, `string`
  - 可空类型：`int?`, `string?`
  - 泛型类型：`List<T>`, `Map<K, V>`
  - 嵌套联合/交叉类型（通过递归实现）

## 限制和注意事项

1. **括号嵌套不支持**：不支持 `(A|B)&C` 这样的复杂嵌套
2. **简单语法**：只支持 `A|B|C` 和 `A&B&C` 的简单组合
3. **类型推断**：阶段3（类型推断集成）暂未实现，当前使用显式类型注解
