# IL 集合函数值调用测试

测试日期：2026-11-13

## 修复范围

集合索引等表达式的静态类型为 `object` 时，IL 现在将其运行期值作为 .NET 委托调用，并将位置参数打包为 `object[]` 传入。这样可调用保存在列表、字典或其他动态容器中的 lambda / 函数值。

## 回归用例

```old8
functions <- {}
for i <- 0, i < 3, i++ {
    functions.Add((value:int) -> value + i)
}

Assert.Equal(10, functions[0](10))
Assert.Equal(11, functions[1](10))
Assert.Equal(12, functions[2](10))
```

该用例同时验证每个循环迭代创建的闭包都会快照自己的循环变量。
