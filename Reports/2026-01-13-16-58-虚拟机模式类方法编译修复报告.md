## 📋 问题概述

在之前的测试中发现，虚拟机模式无法正确调用类的实例方法。所有 VMSuperExpressionTests 测试都失败，错误信息为"未定义的函数: methodName"。

### 根本原因

1. **类方法未被编译**: `BytecodeVisitor.VisitClassInit` 只提取了字段名，完全忽略了类方法的编译
2. **预处理阶段冲突**: `BytecodeCompiler.PreprocessClassDefinitions` 创建了空的类定义，与 `VisitClassInit` 创建的完整类定义冲突
3. **对象实例结构问题**: 使用 `Dictionary<string, object?>` 作为对象实例，无法存储类名信息
4. **方法调用指令错误**: `BytecodeVisitor` 对 `object.method()` 生成 `Call` 指令而不是 `CallMethod` 指令

## 🔧 实施的修复

### 1. 创建 BytecodeObjectInstance 类

**文件**: `Old8Lang/Bytecode/BytecodeObjectInstance.cs` (新建)

创建了专门的对象实例类来存储类名和字段：

```csharp
public class BytecodeObjectInstance
{
    public string ClassName { get; set; } = "";
    public Dictionary<string, object?> Fields { get; set; } = new();

    public BytecodeObjectInstance(string className)
    {
        ClassName = className;
    }
}
```

**作用**: 解决了对象实例无法存储类名的问题，使得 `CallMethod` 指令能够查找对象所属的类。


### 2. 修改 BytecodeVisitor.VisitClassInit

**文件**: `Old8Lang/AST/Visitor/BytecodeVisitor.Statements.cs` (第632-671行)

**修改内容**:
- 遍历 `TypeTemplate.Variates` 提取实例字段和方法
- 遍历 `TypeTemplate.StaticVariates` 提取静态方法
- 调用新版本的 `DeclareClass` 方法，传递方法列表和父类名

**关键代码**:
```csharp
foreach (var (memberId, memberExpr) in typeTemplate.Variates)
{
    if (memberExpr is FuncLangValue funcValue)
    {
        // 这是一个实例方法
        methods.Add((memberId.IdName, funcValue, false));
    }
    else
    {
        // 这是一个实例字段
        fields.Add(memberId.IdName);
    }
}

_compiler.DeclareClass(className, fields, methods, typeTemplate.ParentClassName);
```

**作用**: 确保类方法被正确提取并传递给编译器进行编译。

**作用**: 将类方法编译成字节码函数，并正确注册到类元数据中。


### 4. 修改 BytecodeVisitor.Expressions.cs

**文件**: `Old8Lang/AST/Visitor/BytecodeVisitor.Expressions.cs` (第60-70行)

**修改内容**:
- 将 `object.method()` 调用从 `OpCode.Call` 改为 `OpCode.CallMethod`

**修改前**:
```csharp
Emit(_compiler.IsNativeFunction(methodName) ? OpCode.CallNative : OpCode.Call,
    new object[] { argCount, methodName });
```

**修改后**:
```csharp
// object.method(args) - 调用对象方法
// 使用 CallMethod 指令，它会在对象的类中查找方法
Emit(OpCode.CallMethod, new object[] { argCount, methodName });
```

**作用**: 确保对象方法调用使用正确的指令，能够在类元数据中查找方法。

### 5. 重写 VirtualMachine.CallMethod 指令

**文件**: `Old8Lang/Bytecode/VirtualMachine.cs` (第1617-1689行)

**修改内容**:
- 检查对象是否为 `BytecodeObjectInstance`
- 从对象的类名查找 `ClassMetadata`
- 在类的 `Methods` 列表中查找方法
- 调用方法的 `FunctionMetadata`

**关键代码**:
```csharp
if (obj is BytecodeObjectInstance bytecodeObj)
{
    var classMetadata = _bytecodeFile.Classes.FirstOrDefault(c => c.Name == bytecodeObj.ClassName);
    var methodMetadata = classMetadata.Methods.FirstOrDefault(m => m.Name == methodName);
    
    // 准备方法调用参数：第一个参数是 this（对象本身）
    var methodArgs = new object?[args.Length + 1];
    methodArgs[0] = bytecodeObj;
    Array.Copy(args, 0, methodArgs, 1, args.Length);
    
    // 调用方法（返回值会自动压入栈）
    CallFunction(methodMetadata.Function, methodArgs);
}
```

**作用**: 实现了 Old8Lang 对象方法的正确调用逻辑。
