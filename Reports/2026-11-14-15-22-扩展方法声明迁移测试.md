# 阶段 2「扩展方法声明迁移」测试报告

日期：2026-11-14 15:22

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `ExtensionDeclaration` | 从 Runtime 迁入 `Old8Lang.Syntax/AST/Statements`，扩展方法字段改为 `List<FunctionSyntax>` |
| 运行时适配 | `ExtensionDeclarationRuntimeExtensions.GetExtensionMethods()` 按声明缓存运行时函数值列表；`ResolveTargetType` 移入该扩展类 |
| 函数值缓存 | `FunctionSyntaxRuntimeFactory.GetOrCreateFunc` 成为统一入口，`FuncInit`/`ClassFuncInitStatement` 复用同一缓存 |
| 解析器 | `ExtensionParser` 只收集 `FunctionSyntax`，不再调用 `GetFuncValue()` |
| 消费者更新 | 解释器注册扩展方法、字节码编译器、测试与 Visitor 桩同步更新 |
| 生成代码 | Runtime 节点 54 → 53；遗留 partial 保持 8 |

行为保持：扩展方法注册顺序、`this` 隐式参数与目标类型解析不变；同一语法节点复用同一运行时函数值。
