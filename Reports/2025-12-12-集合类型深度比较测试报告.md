## 实现细节

### 1. TupleLangValue 深度比较

**文件**: `Old8Lang/AST/Expression/Value/TupleLangValue.cs`
**位置**: 第 47-55 行

新增 `Equal` 方法覆盖，支持元组的深度比较：

```csharp
// 覆盖 Equal 方法以支持元组深度比较
public override bool Equal(LangValueType? otherValueType)
{
    if (otherValueType is not TupleLangValue otherTuple)
        return false;

    // 比较两个元素是否都相等
    return Value.Item1.Equal(otherTuple.Value.Item1) &&
           Value.Item2.Equal(otherTuple.Value.Item2);
}
```

**特点**:
- 递归比较元组的两个元素
- 支持嵌套元组比较（如 `((1,2),(3,4))`）
- 支持不同类型元素的元组（如 `("hello", 42)`）

### 2. DictionaryLangValue 修复

**文件**: `Old8Lang/AST/Expression/Value/DictionaryLangValue.cs`

#### 修复 1: Run 方法重复添加问题
**位置**: 第 36-48 行

```csharp
public override LangValueType Run(VariateManager manager)
{
    // 清空之前的值，避免重复添加
    Value.Clear();

    foreach (var tuple in Tuples)
    {
        tuple.Run(manager);
        Value.Add(tuple.Value);
    }

    return this;
}
```

**问题**: 多次调用 Run 方法会导致重复添加键值对
**解决**: 在 Run 方法开始时清空 Value 列表

#### 修复 2: Equal 方法键顺序问题
**位置**: 第 84-117 行

```csharp
public override bool Equal(LangValueType? otherValueType)
{
    if (otherValueType is not DictionaryLangValue otherDict)
        return false;

    // 比较大小
    if (Value.Count != otherDict.Value.Count)
        return false;

    // 检查所有键值对是否相同
    foreach (var (key, value) in Value)
    {
        // 查找相同的键
        bool foundMatch = false;
        foreach (var otherPair in otherDict.Value)
        {
            if (otherPair.Key.Equal(key))
            {
                // 找到相同的键，比较值是否相等
                if (!value.Equal(otherPair.Value))
                    return false;
                foundMatch = true;
                break;
            }
        }

        // 如果找不到相同的键，返回 false
        if (!foundMatch)
            return false;
    }

    return true;
}
```

**问题**: 使用 LINQ 的 FirstOrDefault 可能返回 null，导致比较失败
**解决**: 使用显式循环查找匹配的键，确保正确处理所有情况

## 关键特性

### 1. 递归深度比较
所有集合类型的 `Equal` 方法都支持递归比较：
- 嵌套数组: `[[1,2],[3,4]]`
- 嵌套列表: `[[1,2],[3,4],[5,6]]`
- 嵌套字典: `{"outer":{"inner":123}}`
- 嵌套元组: `((1,2),(3,4))`

### 2. 字典键顺序无关
字典比较不依赖键的顺序：
```old8
dict1 <- {"a": 1, "b": 2, "c": 3}
dict2 <- {"b": 2, "a": 1, "c": 3}
Assert(dict1, dict2)  // ✓ 通过
```

### 3. 类型安全
比较操作会先检查类型：
- 不同类型的集合不相等
- 只有相同类型才进行深度比较

### 4. 空集合支持
正确处理空集合：
- `[] == []` → true
- `{} == {}` → true

## 性能考虑

### 时间复杂度
- **数组/列表**: O(n)，其中 n 是元素数量
- **字典**: O(n×m)，其中 n 是第一个字典的键数量，m 是第二个字典的键数量
- **元组**: O(1)，固定比较两个元素
- **嵌套结构**: 复杂度随嵌套深度线性增长

### 优化建议
对于大型字典，可以考虑：
1. 使用 HashSet 存储已匹配的键，避免重复比较
2. 如果字典支持顺序，可以先排序再比较（O(n log n)）

当前实现优先考虑正确性和可读性，适合中小型数据集。

---

## 已知限制

1. **元组固定为二元组**: 当前实现只支持 `(value1, value2)` 形式的二元组
2. **字典比较性能**: 对于大型字典（>1000 键），嵌套循环可能影响性能
3. **循环引用**: 当前未处理循环引用的情况（如 `a` 包含 `b`，`b` 又包含 `a`）
