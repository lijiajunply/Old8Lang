## 修复类型继承语法问题

### 问题分析
根据 `Old8Lang_Grammar.md` 文档，正确的类型继承语法应该是：
- 类继承：`class Child extends Parent`
- 接口实现：`class Class implements Interface`
- 类使用 mixin：`class Class extends Parent with Mixin1, Mixin2`
- mixin 继承：`mixin ChildMixin extends ParentMixin`

但在 `MixinTests.cs` 文件中，发现了错误的语法：
- 类使用 mixin 时使用了 `<` 符号：`class Sprite < Drawable, Movable`
- mixin 继承使用了 `<` 符号：`mixin VerboseLogger < Logger`
- 类同时继承父类和使用 mixin 时也使用了 `<` 符号：`class ColoredCircle < Shape, Colorable`

### 修复计划
1. 修正 `MixinTests.cs` 文件中的所有 mixin 语法错误：
   - 将类使用 mixin 的 `<` 符号替换为 `with` 关键字
   - 将 mixin 继承的 `<` 符号替换为 `extends` 关键字
   - 确保类同时继承父类和使用 mixin 时语法正确：`class Class extends Parent with Mixin1, Mixin2`

2. 修复的具体位置：
   - 第 47 行：`class Sprite < Drawable, Movable` → `class Sprite with Drawable, Movable`
   - 第 106 行：`mixin VerboseLogger < Logger` → `mixin VerboseLogger extends Logger`
   - 第 118 行：`class Application < VerboseLogger` → `class Application with VerboseLogger`
   - 第 165 行：`class AdvancedCalculator < Calculator` → `class AdvancedCalculator with Calculator`
   - 第 255 行：`class FormComponent < Configurable, Validatable` → `class FormComponent with Configurable, Validatable`
   - 第 337 行：`class ColoredCircle < Shape, Colorable` → `class ColoredCircle extends Shape with Colorable`
   - 第 377 行：`class DatabaseObject < Persistence` → `class DatabaseObject with Persistence`
   - 第 390 行：`class FileSystemObject < Persistence` → `class FileSystemObject with Persistence`
   - 第 448 行：`mixin ExtendedFeatures < BasicFeatures` → `mixin ExtendedFeatures extends BasicFeatures`
   - 第 461 行：`mixin AdvancedFeatures < ExtendedFeatures` → `mixin AdvancedFeatures extends ExtendedFeatures`
   - 第 478 行：`class AdvancedObject < AdvancedFeatures` → `class AdvancedObject with AdvancedFeatures`
   - 第 554 行：`class Player < GameObject, EventSystem` → `class Player extends GameObject with EventSystem`
   - 第 633 行：`class Document < Timed, Versioned` → `class Document with Timed, Versioned`
   - 第 687 行：`mixin C < A, B` → `mixin C with A, B`
   - 第 693 行：`class TestClass < C, B, A` → `class TestClass with C, B, A`
   - 第 739 行：`class Counter < CounterMixin` → `class Counter with CounterMixin`

3. 验证修复：
   - 运行测试确保修复后的代码能够正常工作
   - 检查是否还有其他文件存在类似的语法错误
