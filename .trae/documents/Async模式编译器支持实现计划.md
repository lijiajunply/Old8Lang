# Async模式编译器支持实现计划

## 1. 现状分析
- 解释器模式已完全支持Async/await
- 编译器模式下，Async相关AST节点仅抛出"暂不支持"异常
- 需要实现异步函数的IL代码生成

## 2. 核心实现任务

### 2.1 异步函数初始化节点(AsyncFuncInit)
- 完善`GenerateIl`方法，生成异步函数的IL代码
- 实现异步状态机生成
- 处理异步函数的参数和返回值

### 2.2 异步函数值节点(AsyncFuncLangValue)
- 完善`LoadIlValue`方法，支持异步函数值的IL加载
- 确保异步函数可以被正确调用

### 2.3 await表达式支持
- 实现await表达式的IL生成
- 处理异步任务的等待和结果获取

### 2.4 异步状态机实现
- 生成符合C#异步状态机规范的IL代码
- 处理状态机的状态转换
- 实现异步操作的回调机制

## 3. 测试计划

### 3.1 语法测试
- 在SyntaxTests目录下添加异步语法测试用例

### 3.2 编译器模式测试
- 在CompilerTests目录下添加异步函数测试用例
- 测试基本异步函数调用
- 测试带参数和返回值的异步函数
- 测试嵌套await表达式
- 测试异步函数异常处理

### 3.3 集成测试
- 添加编译器集成测试，验证异步函数的完整编译流程

## 4. 实现步骤

1. 实现AsyncFuncInit.GenerateIl方法
2. 实现AsyncFuncLangValue.LoadIlValue方法
3. 实现await表达式的IL生成
4. 添加基本异步函数编译器测试用例
5. 验证IL代码生成的正确性
6. 添加更多复杂测试用例
7. 优化和完善实现

## 5. 预期目标
- 编译器模式完全支持Async/await语法
- 生成的IL代码能够正确执行异步函数
- 所有测试用例通过
- 与解释器模式行为保持一致
