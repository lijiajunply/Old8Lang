# 更新记录

## Old8Lang 1.0.0 rc3

1. 枚举（Enum）支持
   - 添加枚举声明语法，支持定义命名的整数常量
   - 支持自动值递增（从 0 开始）
   - 支持显式指定枚举成员的整数值
   - 支持混合使用自动值和显式值
   - 枚举成员可用于比较、算术运算和条件语句
   - 添加访问修饰符支持（public、private）
2. 添加多种类型（Mixin，抽象类，接口），泛型，多态
   - 加入了 this 和 super 操作
   - 重构了类型系统，加入了类型模板
   - 
3. 加入三元表达式（if then else 方式）
4. 加入 match 语句 和 is,in 表达式
5. 加入了可空类型假注和类型推断
6. 优化语法，列表声明改为 {...}。同时加入 dict() 和 tuple() 函数
7. 优化 AST 树
8. 优化全局函数、全局静态类和标准库的录入
9. 加入更多标准库
   - 机器学习库
   - 序列化库
   - 数据库和 ORM 支持
   - 图像处理库
   - 模板引擎库
   - 网络操作库（Http操作，MQTT操作，WebApi服务）
10. 加入了第三方库支持（使用全局本地库: ~/.old8lang/packages/）
   - 使用 Old8Lang.PackageManager.Core 进行操作
   - 添加了包管理功能
11. 优化了 cli 命令行
12. 加入了项目导入。使用 o8package.json 文件进行项目管理
13. 优化了模型系统
    - 加入懒加载
    - 加入库缓存功能，增强性能
    - 加入了动态导入
14. 加入了生成器、异步流和异步生成器
15. 加入了多线程和异步操作
    - 添加了锁操作
    - 添加了原子操作、读写锁、Semaphore、Mutex、通道

加入更多测试，但是编译模式还在测试中

## Old8Lang 0.1.0 版本

在0.1.0版本中，可以使用原生函数和引用语句：

```
import os
import console
import net
import math

[import "console.dll" console Write print]
[import "console.dll" console WriteLine printline]
```

引用语句会引用相关内容，使其类和方法加载到该文件上：

import `<context>`

原生函数需要使用到C#的dll，该语法需要3~4个参数：

[import `<dllname> <classname> <methodname> <nativemethodname>`]
