## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `SetStatement`、`ForStatement` | 从 `Old8Lang.Runtime/AST/Statement` 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| Visitor 分派 | `IVisitor` 新增 `VisitSetStatement`、`VisitForStatement`；重新生成后 Runtime 节点 69 |
| 编译辅助 | `ComputeGlobalValueType`、`TryEmitGlobalStore`、`EmitNumericConversion`、`IsNumericType` 移入 `SetStatementRuntimeExtensions`；循环变量遮蔽与 `IsSimpleCountingLoop` 移入 `ForStatementRuntimeExtensions` |
| 可见性调整 | Runtime 访问 `SetStatement._leftExpression` 的地方改用既有公开属性 `LeftExpression`（该字段仍不公开） |
| 生成代码 | 两个旧 `*.Accept.generated.cs` 归档到 `backups/trash-2026-11-14/` |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 23 → 21 |

行为保持：普通变量/成员/索引赋值、元组解构赋值、全局槽位提升、空字典注解与数值转换判断均沿用原实现；
for 的初始化求值顺序、循环变量遮蔽/恢复与计数循环启发式未变。
