# 实现 in 表达式和优化 for-in 循环解析

## 目标
1. 添加 `in` 表达式支持，允许语法如 `a in b`
2. 优化 for-in 循环解析，确保与 in 表达式正确区分
3. 实现 in 表达式的解释和编译逻辑

## 实现步骤

### 1. 在 ExpressionParser 中添加 in 操作符支持
在 `ParseBinaryExpression` 方法中添加对 `in` 操作符的支持，使其能够被解析为 `Operation` 对象。

### 2. 在 Operation 类中实现 in 操作符的解释逻辑
在 `Operation.Run` 方法中添加对 `in` 操作符的处理：
- 检查右侧表达式是否为 `ILangList` 类型
- 如果是，调用其 `In` 方法检查左侧值是否存在于集合中
- 返回相应的布尔值

### 3. 在 Operation 类中实现 in 操作符的编译逻辑
在 `Operation.OutputType` 和 `Operation.LoadIlValue` 方法中添加对 `in` 操作符的编译支持：
- 生成 IL 代码检查右侧表达式是否为集合类型
- 调用集合的 `Contains` 方法或类似方法实现成员检查
- 返回布尔类型结果

### 4. 优化 for-in 循环的检测逻辑
在 `StatementParser.ParseStatement` 方法中改进 for-in 循环的检测逻辑：
- 确保只有在 `for` 关键字后直接跟着标识符和 `in` 关键字时，才解析为 for-in 循环
- 避免将普通 in 表达式误识别为 for-in 循环

## 具体修改点

### 修改 1: ExpressionParser.cs - 添加 in 操作符支持
```csharp
// 在 ParseBinaryExpression 方法中添加对 in 操作符的支持
while (CurrentToken.Type is LangTokenType.In or LangTokenType.LessThanEquals or LangTokenType.GreaterThanEquals
       or LangTokenType.Equals
       or LangTokenType.NotEquals or LangTokenType.LessThan or LangTokenType.GreaterThan)
{
    var operatorToken = CurrentToken;
    var position = CreateSourcePosition(operatorToken);
    Expect(operatorToken.Type);
    var right = ParseNumberOpera1();
    left = new Operation(left, operatorToken.Type, right, position);
}
```

### 修改 2: Operation.cs - 实现 in 操作符的解释逻辑
```csharp
// 在 Run 方法中添加 in 操作符处理
if (Opera == LangTokenType.In)
{
    var rightValue = Right.Run(manager);
    if (rightValue is ILangList list)
    {
        var leftValue = Left.Run(manager);
        return new BoolLangValue(list.In(leftValue));
    }
    throw new InvalidOperationError(this, "in 操作符右侧必须是集合类型");
}
```

### 修改 3: Operation.cs - 实现 in 操作符的编译逻辑
```csharp
// 在 OutputType 和 LoadIlValue 方法中添加 in 操作符的编译支持
case LangTokenType.In:
{
    // 实现 in 操作符的 IL 生成逻辑
    // 检查右侧是否为集合类型，然后调用 Contains 方法
    return typeof(bool);
}
```

### 修改 4: StatementParser.cs - 优化 for-in 检测
```csharp
// 改进 for-in 循环的检测逻辑
if (CurrentToken.Type == LangTokenType.For)
{
    // 检查下一个 token 是否为标识符，然后是 in 关键字
    var nextToken = Peek();
    var inToken = Peek(2);
    if (nextToken.Type == LangTokenType.Identifier && inToken.Type == LangTokenType.In)
    {
        return ParseForInStatement();
    }
    // 其他情况解析为普通 for 循环
    return ParseForStatement();
}
```

## 测试计划

### 1. 语法测试
- 测试 `a in [1, 2, 3]` 这样的基本 in 表达式
- 测试 `for item in [1, 2, 3] { ... }` 这样的 for-in 循环
- 测试嵌套情况，如 `if (a in [1, 2, 3]) { for item in [4, 5, 6] { ... } }`

### 2. 解释模式测试
- 测试 in 表达式在解释模式下的正确性
- 测试 for-in 循环在解释模式下的正确性

### 3. 编译模式测试
- 测试 in 表达式在编译模式下的正确性
- 测试 for-in 循环在编译模式下的正确性

## 预期效果
- 能够正确解析和执行 `a in b` 这样的表达式
- 能够正确解析和执行 `for item in collection { ... }` 这样的 for-in 循环
- 确保 for-in 循环和 in 表达式不会相互混淆
- 支持各种集合类型（数组、列表、字典等）的 in 操作
