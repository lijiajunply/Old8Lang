## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `IfChild`、`IfStatement`、`DeferStatement` | 从 `Old8Lang.Runtime/AST/Statement` 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| Visitor 分派 | `IVisitor` 新增 `VisitIfStatement`、`VisitDeferStatement`；`IfChild` 保持内部辅助语义（`Accept` 抛 `NotSupportedException`，不进入生成接口） |
| 死代码清理 | `IfChild.GenerateConditionIl` 全仓无调用方，随节点迁移归档到 `backups/trash-2026-11-14/IfChild.Split.cs`（未删除） |
| 生成代码 | 重新生成后 Runtime 节点 73；两个旧 `*.Accept.generated.cs` 归档到 `backups/trash-2026-11-14/` |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 26 → 25 |

行为保持：`IfStatement` 的 `Count`/索引器与 `ToString`、`IfChild` 的条件/块访问、`DeferStatement`
的 LIFO 收集与越界返回空块均未改动；`IfStatement` 的解释与 IL 生成仍由既有 Visitor 处理。
