## 功能概述

嵌套切片访问 (Nested Slice Access) 是 Old8Lang 的高级特性，允许对嵌套数据结构（多维数组、嵌套列表、嵌套字典等）进行链式索引和切片操作。

### 支持的语法

```old8
// 二维数组切片
matrix[0][1:3]           // 获取第一行的第2-3个元素

// 三维数组切片
cube[0][0][0:2]          // 三重嵌套访问并切片

// 嵌套列表切片
nestedList[1][0:2]       // 嵌套列表的切片访问

// 嵌套字典访问后切片
data["matrix"][0][1:3]   // 字典值为数组时的嵌套切片
```

## 实现细节

### 核心组件

#### 1. AST 节点: `NestedSliceAccess`

**文件位置**: `Old8Lang/AST/Expression/Intermediates/NestedSliceAccess.cs`

**主要特性**:
- 接受任意 `LangExpression` 作为基础表达式（不限于 `LangListItem`）
- 支持可选的 `start`、`end`、`step` 参数
- 在 `Run` 方法中动态检查基础表达式结果是否支持切片操作
- 支持所有实现了 `ILangList` 接口的类型

**关键代码**:
```csharp
public partial class NestedSliceAccess(
    LangExpression baseExpression,
    LangExpression sliceStart,
    LangExpression? sliceEnd = null,
    LangExpression? sliceStep = null,
    SourcePosition position = default)
    : LangValueType(position)
```

#### 2. Parser 逻辑: `ExpressionParser`

**文件位置**: `Old8Lang/LangParser/Parsers/ExpressionParser.cs`

**解析策略**:
- 使用向前查找 (lookahead) 检测冒号 `:` 来区分索引访问和切片访问
- 对于切片语法，根据左操作数类型选择创建 `SliceLangValue` 或 `NestedSliceAccess`
- 支持链式嵌套：`LangId` → `LangListItem` → `NestedIndexAccess` → `NestedSliceAccess`

**处理逻辑**:
```old8
cube[0]       →  LangListItem(cube, 0)
cube[0][0]    →  NestedIndexAccess(LangListItem, 0)
cube[0][0][0:2] →  NestedSliceAccess(NestedIndexAccess, 0, 2)
```

## 与原提案对比

### 原提案示例 1: 多维数组切片
```old8
matrix <- [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
subMatrix <- matrix[0..2][1..3]  // [[2, 3], [5, 6]]
```

**实现状态**: ✅ **已实现**（语法略有不同）

**实际语法**:
```old8
matrix <- [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
subMatrix <- matrix[0][1:3]  // [2, 3]
```

**说明**:
- Old8Lang 使用 `:` 而非 `..` 作为切片分隔符
- `matrix[0..2]` 在 Old8Lang 中应写为 `matrix[0:2]`
- 切片语法已统一为 `[start:end:step]` 格式
