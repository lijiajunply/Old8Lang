## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `BreakStatement`、`ContinueStatement`、`ReturnStatement`、`YieldStatement` | 从 `Old8Lang.Runtime/AST/Statement` 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变；节点自带 `Accept`，改用 Syntax 的 `IVisitor<TResult>` 分派 |
| `Old8Lang.Syntax/AST/IVisitor.cs` | 新增 `VisitReturnStatement`、`VisitYieldStatement`、`VisitBreakStatement`、`VisitContinueStatement` |
| `IVisitor.generated.cs` | 由生成器重新生成，Runtime 节点数 80 → 76；四个节点的旧 `*.Accept.generated.cs` 移入废纸篓 |
| `ReturnStatementRuntimeExtensions` | `ReturnStatement` 的数值转换、类型兼容判断从语法节点移入 Runtime；`CompilerVisitor` 调用方同步更新 |
| `ArchitectureProjectDependencyTests` | 遗留 `*.Split.cs` 基线 28 → 27（`ReturnStatement.Split.cs` 已转为独立辅助类） |
| `ScalarLiteralExpressionTests` | 语法程序集归属断言与 `SyntaxOnlyVisitor` 桩补全四个新方法 |

行为保持：解释、IL、VM 的 break/continue/return/yield 语义未改；仅 `BreakStatement`/`ContinueStatement`
未实现的子语句索引器由 `InvalidOperationError` 改为 `NotSupportedException`（无子语句，正常遍历不触发）。
