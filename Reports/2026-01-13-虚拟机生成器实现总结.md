## 二、核心组件

### 1. 生成器状态管理 (`GeneratorState.cs`)

**位置**: `Old8Lang/Bytecode/GeneratorState.cs`

**功能**:
- 保存生成器的执行状态（指令指针、局部变量、操作数栈）
- 支持状态的保存和恢复
- 管理生成器的生命周期（未开始、暂停、完成）

**关键方法**:
- `SaveState()` - 在yield时保存当前执行状态
- `RestoreState()` - 在MoveNext时恢复执行状态
- `Complete()` - 标记生成器已完成

### 2. 生成器对象类型 (`BytecodeGeneratorLangValue.cs`)

**位置**: `Old8Lang/Bytecode/BytecodeGeneratorLangValue.cs`

**功能**:
- 表示虚拟机模式下的生成器对象
- 实现`IEnumerable<LangValueType>`接口，支持for-in循环
- 提供`MoveNext()`方法推进生成器执行

**关键特性**:
- 持有生成器ID和虚拟机引用
- 管理当前值和完成状态
- 支持迭代器模式

### 3. 字节码生成 (`BytecodeVisitor`)

**修改文件**: `Old8Lang/AST/Visitor/BytecodeVisitor.Statements.cs`

**实现**:
```csharp
public Instruction? VisitYieldStatement(YieldStatement node)
{
    // 1. 生成 yield 表达式的字节码（将值压入栈）
    node.YieldExpression.Accept(this);

    // 2. 生成 Yield 指令（暂停执行并返回栈顶值）
    Emit(OpCode.Yield);

    return null;
}
```

### 4. 生成器检测 (`BytecodeCompiler`)

**修改文件**: `Old8Lang/Bytecode/BytecodeCompiler.cs`

**实现**:
- 添加`ContainsYieldStatement()`方法递归检测函数体中是否包含yield语句
- 在`CompileFunction()`中自动设置`FunctionMetadata.IsGenerator`标记

**关键代码**:
```csharp
// 检测函数是否包含yield语句
bool isGenerator = ContainsYieldStatement(body);

var func = new FunctionMetadata
{
    Name = funcName,
    Parameters = parameters,
    DefaultValues = defaultValues,
    IsAsync = false,
    IsGenerator = isGenerator  // 设置生成器标记
};
```

### 5. 虚拟机执行支持 (`VirtualMachine.cs`)

**修改文件**: `Old8Lang/Bytecode/VirtualMachine.cs`

**实现内容**:

#### 5.1 生成器管理字段
```csharp
// Generator 管理
private readonly Dictionary<int, GeneratorState> _generators = new();

```

#### 5.2 Yield指令执行
- 从栈中弹出yield的值
- 保存当前执行状态（IP、局部变量、栈）
- 设置生成器为暂停状态
- 通过设置IP到函数末尾来暂停执行

#### 5.3 ResumeGenerator方法
```csharp
public LangValueType? ResumeGenerator(int generatorId)
```
- 恢复生成器的执行状态
- 继续执行直到下一个yield或函数结束
- 返回yield的值或null（已完成）

#### 5.4 生成器函数调用拦截
在`OpCode.Call`指令中添加生成器检测：
```csharp
// 检查是否是生成器函数
if (function.IsGenerator)
{
    // 创建生成器状态
    var generatorId = _nextGeneratorId++;
    var generatorState = new GeneratorState(function, args...);
    _generators[generatorId] = generatorState;

    // 创建生成器对象并压入栈
    var generatorValue = new BytecodeGeneratorLangValue(generatorId, this);
    _stack.Push(generatorValue);
}
```

## 四、技术实现细节

### 4.1 状态保存机制

生成器在yield时需要保存完整的执行状态：
- **指令指针（IP）**: 记录下一条要执行的指令位置
- **局部变量**: 深拷贝所有局部变量到GeneratorState
- **操作数栈**: 深拷贝栈内容，确保状态完整

### 4.2 状态恢复机制

在MoveNext时恢复执行状态：
- 创建新的CallFrame并设置GeneratorId
- 恢复IP、局部变量和操作数栈
- 继续执行直到下一个yield或函数结束

### 4.3 生成器检测算法

使用递归遍历AST检测yield语句，支持嵌套结构（if、while、for等）。

- 编译器模式（-c）的IL代码生成尚未实现

## 七、使用示例

### 基本用法

```old8
// 定义生成器函数
func counter(max:int) -> void {
    i <- 0
    while i < max {
        yield i
        i <- i + 1
    }
}

// 创建生成器
gen <- counter(5)

// 使用for-in循环遍历（推荐）
for value in gen {
    PrintLine(value.ToStr())
}
```
