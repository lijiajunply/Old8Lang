# 全面语法测试计划 - 覆盖所有情况

## 1. 测试目标
- 覆盖所有EBNF定义的语法规则
- 覆盖所有语法文档中提到的语法
- 测试普通语法情况
- 测试边界情况
- 测试错误语法情况
- 测试语法解析的严格性
- 测试语法规则的一致性

## 4. 测试执行流程

### 4.1 语法测试
1. 运行现有语法测试脚本：`bash run_syntax_tests.sh`
2. 添加所有新增测试文件到SyntaxTests目录
3. 运行扩展后的语法测试
4. 验证所有EBNF规则和语法文档内容都被覆盖

### 4.2 解释模式测试
1. 对所有测试文件运行解释模式测试：`dotnet run --project Old8Lang.App -- -f <file>`
2. 验证解释执行结果正确性
3. 记录解释模式下的错误和异常

### 4.3 编译模式测试
1. 对所有测试文件运行编译模式测试：`dotnet run --project Old8Lang.App -- -c <file>`
2. 验证编译输出和执行结果
3. 记录编译模式下的错误和异常

### 4.4 严格语法解析分析
1. 分析语法解析器对所有规则的处理情况
2. 验证语法解析的严格性
3. 检查错误处理机制
4. 分析语法规则的一致性

## 5. 测试用例设计

### 5.1 基础语法测试用例

```old8
// 字面量测试
str <- "hello"
n <- 123
d <- 3.14
c <- 'a'
t <- true
f <- false

// 标识符测试
valid_id <- 1
type_annotated_id:int <- 2
// invalid_id <- 3  // 关键字作为标识符

// 赋值测试
var1 <- 100
var2:int <- 200
var3:double <- 3.14
```

### 5.2 表达式测试用例

```old8
// 算术表达式
a <- 10 + 20 - 5
b <- 10 * 20 / 5
c <- 10 % 3  // 取模运算符

// 比较表达式
d <- a == b
e <- a > c
f <- a <= b

// 逻辑表达式
g <- d and e
h <- d or f
i <- g xor h
j <- not i

// 复杂表达式
k <- (a + b) * (c - d) / (e or f)
```

### 5.3 边界测试用例

```old8
// 深层嵌套
if true {
    if true {
        if true {
            if true {
                if true {
                    if true {
                        if true {
                            if true {
                                if true {
                                    if true {
                                        PrintLine("10层嵌套")
                                    }
                                }
                            }
                        }
                    }
                }
            }
        }
    }
}

// 空结构
empty_block {}
empty_list <- []
empty_dict <- {}
empty_func() {}
```

### 5.4 错误语法测试用例

```old8
// 语法错误
missing_keyword if a > 5 PrintLine("error")  // 缺少if
unmatched_parens <- (1 + 2  // 缺少右括号
invalid_id <- 123abc  // 无效标识符
wrong_assignment <- a = 10  // 错误的赋值运算符

// 语义错误
undefined_var <- nonexistent_var  // 未定义变量
type_mismatch:int <- "string"  // 类型不匹配

// 边界错误
invalid_index <- [1, 2, 3][10]  // 超出范围的索引
```
