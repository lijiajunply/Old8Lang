# 泛型支持完善与验证计划

根据代码分析，编译器模式下的泛型支持（函数和类）已有相当完整的代码基础，包括 `GenericMethodSpecializer` 和 `GenericClassSpecializer`。当前的任务主要是验证现有实现的正确性，修复潜在问题，并更新文档。

## 1. 验证阶段：创建测试用例
我们将创建两个核心测试文件来验证功能：

### 1.1 泛型函数测试 (`CompilerTests/generic_function.old8`)
- **基础泛型函数**: 定义 `func identity<T>(x:T) -> T` 并调用。
- **多类型参数**: 定义 `func pair<K,V>(k:K, v:V) -> string` 并调用。
- **类型推断**: 测试不显式指定类型参数的调用（如 `identity(123)`）。
- **复杂类型**: 使用 `list<T>` 等泛型类型作为参数。

### 1.2 泛型类测试 (`CompilerTests/generic_class.old8`)
- **基础泛型类**: 定义 `class Box<T> { value:T ... }`。
- **泛型方法**: 在泛型类中定义使用类型参数的方法。
- **实例化**: 测试 `Box<int>(123)` 和 `Box<string>("hello")`。
- **字段访问**: 验证泛型字段的读写。
