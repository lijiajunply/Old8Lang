# IL C 风格 for 循环变量作用域修复测试

测试日期：2026-11-13

## 修复范围

IL 编译器会在每个 C 风格 `for` 的初始化前计算右侧表达式，再创建循环变量的独立局部绑定；离开循环时恢复同名外层局部或全局绑定。嵌套循环不再复用外层循环变量。

## 回归用例

```old8
i <- 100
total <- 0
for i <- 0, i < 3, i++ {
    for i <- 0, i < 2, i++ {
        total <- total + 1
    }
}
Assert.Equal(6, total)
Assert.Equal(100, i)
```

另有用例验证未声明的循环变量在循环结束后使用时，IL 编译会报告 `变量 'i' 未声明`。

## 已知限制

保存 loop lambda 后通过 `functions[index]()` 调用时，集合索引表达式在 IL 中仍为 `object`，不能作为函数值调用；该问题已归入 Todo 的 lambda “集合中的函数值调用”项，未包含在本次循环作用域修复中。
