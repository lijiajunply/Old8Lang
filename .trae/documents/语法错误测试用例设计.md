# 语法错误测试用例设计

## 1. 测试目标

根据Old8Lang的EBNF语法和语法文档，设计全面的语法错误测试用例，覆盖所有主要语法规则的错误情况，验证解析器能够正确识别和报告语法错误。

- 无效字符
- 未闭合的字符串和字符字面量
- 无效标识符
- 无效的数值字面量

### 2.2 语法结构错误
- 括号不匹配（(), {}, []）
- 缺少关键字

- 无效表达式

### 2.3 声明和赋值错误
- 无效变量声明
- 无效赋值语句
- 无效类型注解

### 2.4 控制流语句错误
- 无效if-elif-else语句
- 无效for循环语句
- 无效while循环语句
- 无效for-in语句
- 无效switch语句

### 2.5 函数和类错误
- 无效函数声明
- 无效函数调用
- 无效类声明
- 无效类实例化
- 无效方法调用

### 2.6 表达式错误
- 无效二元表达式
- 无效逻辑表达式
- 无效算术表达式
- 无效成员访问表达式

## 3. 测试用例设计

### 3.1 词法错误测试
```old8
// 无效字符
invalid_char <- @
invalid_char <- #
invalid_char <- $invalid

// 未闭合的字符串
unclosed_string <- "hello world
unclosed_char <- 'a

// 无效标识符
123invalid <- 10
invalid-identifier <- 20
invalid.identifier <- 30

// 无效数值字面量
invalid_int <- 0x123 // 不支持十六进制
invalid_float <- 1.2.3 // 多个小数点
invalid_float <- .123 // 缺少前导数字
```

### 3.2 语法结构错误测试
```old8
// 括号不匹配
if (a > 5 {
    PrintLine("缺少右括号")
}

if (a > 5) {
    PrintLine("缺少右大括号")

// 缺少关键字
if a > 5 {
    PrintLine("缺少左括号")
}

for i <- 0, i < 10, i++
    PrintLine("缺少大括号")
```

### 3.3 声明和赋值错误测试
```old8
// 无效赋值运算符
a = 10 // 应该使用 <-
a := 20 // 应该使用 <-
a <= 30 // 应该使用 <-

// 无效类型注解
invalid_type <- 10 : invalid_type
invalid_type : <- 20

// 链式赋值
a <- b <- 10 // 不支持链式赋值
```

### 3.4 控制流语句错误测试
```old8
// 无效if语句
if 10 {
    PrintLine("缺少表达式")
}

if {
    PrintLine("缺少表达式和括号")
}

// 无效elif语句
if (a > 5) {
    PrintLine("true")
} elif {
    PrintLine("缺少表达式")
}

// 无效else语句
if (a > 5) {
    PrintLine("true")
} else (a < 5) {
    PrintLine("else不能有条件")
}

// 无效for循环
for i <- 0; i < 10; i++ {
    PrintLine("应该使用逗号分隔")
}

for i <- 0, i < 10 {
    PrintLine("缺少递增语句")
}

// 无效while循环
while {
    PrintLine("缺少表达式和括号")
}

// 无效switch语句
switch {
    PrintLine("缺少表达式")
}

switch (a) {
    case 1
        PrintLine("缺少大括号")
}
```

### 3.5 函数和类错误测试
```old8
// 无效函数声明
func 123invalid() {
    return 0
}

func invalid-param() {
    return 0
}

func invalid return type() -> {
    return 0
}

// 无效函数调用
invalid_func() // 函数未定义
func_call(1, 2, ) // 多余的逗号

// 无效类声明
class 123Invalid {
    // 类体
}

class Invalid {
    invalid-member <- 10 // 无效成员声明
}

// 无效类实例化
obj <- Invalid( // 缺少右括号
obj <- Invalid(1, 2, ) // 多余的逗号
```

### 3.6 表达式错误测试
```old8
// 无效二元表达式
10 + * 20
10 < > 20
10 == = 20

// 无效逻辑表达式
true and or false
not not not true

// 无效算术表达式
10 + 
+ 10

// 无效成员访问
obj. // 缺少成员名
obj..member // 连续点号

// 无效索引访问
array[ // 缺少索引和右括号
array[] // 缺少索引
array[1, 2] // 无效索引语法

// 无效三元表达式
a > b ? a // 缺少冒号和else分支
a > b : a : b // 多余的冒号
```

### 3.7 复合数据类型错误测试
```old8
// 无效数组初始化
invalid_array <- [1, 2, ] // 多余的逗号
invalid_array <- [1, 2, 3 // 缺少右括号

// 无效列表初始化
invalid_list <- list[ // 缺少元素和右括号
invalid_list <- list[1, 2, ] // 多余的逗号

// 无效字典初始化
invalid_dict <- {"key" 10} // 缺少冒号
invalid_dict <- {"key": } // 缺少值
invalid_dict <- {"key": 10, } // 多余的逗号

// 无效元组初始化
invalid_tuple <- (1, 2, ) // 多余的逗号
invalid_tuple <- (1 // 缺少右括号

// 无效范围表达式
invalid_range <- [1~] // 缺少结束值
invalid_range <- [~10] // 缺少起始值
invalid_range <- [1~10 // 缺少右括号
```

### 3.8 特殊语法错误测试
```old8
// 无效字符串模板
invalid_template <- $"hello {name // 未闭合的占位符
invalid_template <- $"hello } // 无效的占位符

// 无效lambda表达式
invalid_lambda <- () -> // 缺少表达式或块
invalid_lambda <- (a, b -> a + b // 缺少右括号

// 无效类型转换
invalid_cast <- 10 as invalid_type
invalid_cast <- 10 as // 缺少目标类型

// 无效导入语句
import // 缺少模块名
import 123invalid // 无效模块名

// 无效native语句
[import "Old8LangLib" Time // 缺少方法名和右括号
[import Old8LangLib Time GetTimeNow] // 缺少引号
```

## 4. 测试文件组织

将测试用例组织到以下文件中：

1. **test_lexical_errors.old8** - 词法错误测试
2. **test_syntax_structure_errors.old8** - 语法结构错误测试
3. **test_declaration_errors.old8** - 声明和赋值错误测试
4. **test_control_flow_errors.old8** - 控制流语句错误测试
5. **test_function_class_errors.old8** - 函数和类错误测试
6. **test_expression_errors.old8** - 表达式错误测试
7. **test_complex_type_errors.old8** - 复合数据类型错误测试
8. **test_special_syntax_errors.old8** - 特殊语法错误测试

## 5. 测试执行

使用以下命令执行语法测试：
```bash
dotnet run --project Old8Lang.App -- -s SyntaxTests/<test-file.old8>
```

## 6. 预期结果

所有测试用例都应该触发语法错误，并显示清晰的错误信息，包括错误位置和建议的修复方法。

## 7. 测试目标

- 覆盖所有主要语法规则的错误情况
- 验证解析器能够正确识别和报告语法错误
- 确保错误信息清晰、准确，包含足够的上下文信息
- 测试用例易于理解和维护

通过全面的语法错误测试，可以提高Old8Lang解析器的健壮性和用户友好性，确保用户能够获得清晰的错误反馈，便于调试和修复代码。
