- **测试时间**: 2026-10-10 19:23
- **测试类型**: 实例方法跨模式补齐（续轮）——VM 模式 `Thread.Then` / `WithTimeout` / `Retry` / `Cancel`
- **测试目标**: 关闭上一轮唯一未完成的项。上一轮报告：
  `Reports/2026-10-10-19-03-实例方法跨模式补齐测试.md`（该轮成果已提交为 `a5234144`）。
- **环境**: macOS / .NET 10.0.100

## 1. 结论

| 方法 | VM 状态 | 验证 |
|------|---------|------|
| `Thread.Then(callback)` | ✅ | continuation 必须返回线程，等待其完成后把结果作为新线程结果 |
| `Thread.WithTimeout(ms)` | ✅ | 正常完成取回结果；超时抛 `TimeoutException`（已实测捕获） |
| `Thread.Retry(n, delayMs?)` | ✅ | 重新执行 `spawn` 时登记的函数对象与参数 |
| `Thread.Cancel()` | ✅ | 启动前取消生效（`Join` 抛「线程被取消」）；运行中协作为 no-op |

**至此原清单的 14 个 VM 方法全部落地**（Array 6 + Task 4 + Thread 4）。

## 2. 为什么需要单独实现

上一轮核查到的阻塞点：这 4 个方法原本的 `TargetType` 是 `ThreadLangValue`，而 VM 的线程对象是
`VMThreadLangValue`（整数线程 id + `Concurrency.ResourceManager`），
VM 分发（`VirtualMachine.Helpers.ReflectionAndTasks.cs:38/60/65`）的精确匹配与
`VMTypeMapper` 等价映射都得不到 `ThreadLangValue`，方法体根本不会执行。
同时 VM 线程模型缺少取消 / 超时等待 / 重新执行所需的信息。

本轮做法：

1. `Old8Lang/Concurrency/VMThreadWrapper.cs`
   - `RequestCancel()`：设置取消标记；`Start()` 时若已请求取消则不执行动作，直接以
     `OperationCanceledException("线程被取消")` 完成（`Join()` 会抛出它）；
   - `WaitCompletion(ms)`：带超时等待完成（已完成但异常时返回 `true`，由 `Join()` 抛原始异常）。
2. `Old8Lang/Concurrency/ResourceManager.cs`
   - 新增 `CancelThread(id)` / `WaitThreadCompletion(id, ms)`；
   - 新增线程负载表 `RegisterThreadPayload(id, 函数对象, 参数)` / `TryGetThreadPayload(...)`
     （`Retry` 需要重新执行原始函数；`DisposeThread` 会清理）。
3. `Old8Lang/GlobalFunctions/Implementations/SpawnFunction.cs`：VM 路径创建线程后登记负载。
4. `Old8Lang/InstanceMethods/Implementations/Thread/VmThreadMethods.cs`（新）：4 个 VM 专属方法类，
   `TargetType => typeof(VMThreadLangValue)`，并在 `InstanceMethodInitializer` 中注册；
   continuation / 函数对象通过 `ExecuteFunctionObjectInWorker` 在 worker 虚拟机上执行
   （`VMContext.CurrentVM` 是 `[ThreadStatic]`，不能在线程池线程上复用当前 VM 的求值栈）。
5. 顺带修复 `Old8Lang/AST/Expression/Value/Async/VMThreadLangValue.cs` 的打印自递归
   （补 `ToString` / `ToDisplayString`；原实现 `GetValue()` 返回自身 + 基类 `ToString()` 递归 → 栈溢出）。

## 3. 实测

**测试文件**：`TestFiles/VirtualMachine/thread_methods_vm_test.old8`

```bash
dotnet Old8Lang.App/bin/Debug/net10.0/Old8Lang.App.dll -vm TestFiles/VirtualMachine/thread_methods_vm_test.old8
```

输出：

```
Then OK
WithTimeout OK
WithTimeout 超时 OK
Retry OK
Cancel 启动前 OK
Cancel 运行中 OK
线程对象可打印: Thread#12
All Thread VM Tests Passed
```

覆盖的边界：

- `Then`：continuation 返回线程并等待其结果；
- `WithTimeout`：正常路径取回 7；`Sleep(300)` + 超时 20ms → 捕获到超时异常；
- `Retry`：`spawn(work).Retry(2)` → `Join()` = 7；
- `Cancel`：启动前取消 → `Join()` 抛异常（已捕获）；已启动线程取消 → 结果仍为 7（协作式语义）；
- `PrintLine(线程)` 输出 `Thread#12`（修复前会栈溢出）。
