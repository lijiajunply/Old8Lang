# 支持类字段不初始化声明

## 问题分析

目前 Old8Lang 只支持带有初始化值的类字段声明，如 `public x <- 1`，但不支持 `public x` 这样的未初始化字段声明。

## 实现计划

### 1. 修改语法解析逻辑

* 修改 `StatementParser.ParseStatement` 方法，在处理带有修饰符的语句时，检查是否为标识符且后续没有赋值符号

* 当遇到 `public x` 这样的模式时，创建一个赋值为 `NullLangValue` 的字段声明

### 2. 具体实现步骤

* 在 `StatementParser.ParseStatement` 方法中，当处理完修饰符后，检查当前 token 是否为标识符

* 如果是标识符，检查下一个 token 是否为赋值符号

* 如果没有赋值符号，创建一个赋值为 `NullLangValue` 的 `SetStatement`

* 确保这个 `SetStatement` 能正确转换为 `ClassFieldSetStatement`

### 3. 测试验证

* 创建测试用例验证未初始化字段声明的正确性

* 确保未初始化字段被正确赋值为 null

* 确保解释模式和编译模式都能正常工作

## 预期效果

支持以下语法：

```
class T {
  public x
  public y <- 2
}
```
