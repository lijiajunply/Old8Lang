# 阶段 3.1 解释后端拆分测试报告

日期：2026-11-14 16:44  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3「拆分执行后端」的解释后端子阶段。

## 目标

把解释执行引擎从 `Old8Lang.Runtime` 拆到独立程序集，使 Runtime 不再在编译期引用
`InterpreterVisitor`，同时保持解释、IL、VM 三种模式的行为与既有基线一致。

## 改动

1. 新增 `Old8Lang.Interpreter` 程序集，只引用 `Old8Lang.Runtime`。迁入：
   - `InterpreterVisitor` 及 `InterpreterVisitor.{Expressions,Statements,Values}.cs`；
   - `ScalarLiteralVisitors.cs`、`CallExpressionVisitors.cs`、`LambdaExpressionVisitors.cs`
     中的解释器片段（IL/字节码/类型推断片段暂留 Runtime，供后续子阶段迁出）；
   - `InterpreterBackend` 注册入口与模块初始化兜底注册。
2. Runtime 新增 `Old8Lang.AST.Visitor.RuntimeVisitors` 契约：
   - `RegisterInterpreter(Func<VariateManager, IRuntimeVisitor<LangValueType>>)`；
   - `CreateInterpreter(VariateManager)`，未注册时抛出带组合根指引的异常。
3. 替换 Runtime 内 364 处 `new InterpreterVisitor(...)`（173 个文件）为契约调用；
   删除 `CompilerVisitor`/`BytecodeVisitor` 中两个不可达的 `VisitInterpreterVisitor` 方法。
4. 组合根 `Old8HostBuilder` 构造时显式 `InterpreterBackend.Register()`；
   App、LSP、Benchmarks、Tests 显式引用 `Old8Lang.Interpreter`。
5. 新增 `BackendAssemblyBoundaryTests` 四条门禁：
   Runtime 程序集不引用任何后端；解释程序集只引用 Runtime 且不引用其他后端/官方模块；
   解释后端可通过契约注册并创建；Runtime 源码不得再出现 `InterpreterVisitor`。
6. Runtime 对解释后端开放 `InternalsVisibleTo`，暂复用内部执行辅助；后续收敛公开 API 后移除。

## 验证

构建（`/usr/local/share/dotnet/dotnet build Old8Lang.sln`）：0 错误。仅 NU1900 缓存警告与仓库既有分析器警告。

| 测试组 | 结果 |
| --- | --- |
| `Old8Lang.Tests.Architecture` | 49 通过，0 失败 |
| `Old8Lang.Tests.Interpreter` | 1967 通过，1 跳过，0 失败 |
| `Old8Lang.Tests.VirtualMachine` | 1082 通过，0 失败 |
| `Old8Lang.Tests.Compiler.Expressions` | 179 通过，41 失败；与 HEAD 基线逐项完全一致 |

说明：

- 测试主机需 `.NET 10` 运行时，本机默认 `dotnet` 指向 11.0.0，执行测试时使用
  `/usr/local/share/dotnet/dotnet`。
- Compiler 全域与 `Compiler.Expressions` 的失败在未改动的 HEAD 上以同样数量复现
  （`Compiler.Expressions` 均为 41 失败；Compiler 全域两次都在 IL 异常后中止测试主机），
  属于 `Todo.md` 已记录的 IL 既有问题，不是本子阶段引入。
- 解释器回归数量与阶段 2 完成时（1967/1968）一致。

## 遗留

- `LangInterpreter`、`VariateManager`、`ScopeLayer` 等解释期状态仍在 Runtime，作为运行时值
  与实例方法共享契约使用；解释语义入口（Visitor）已独立。若要进一步把作用域状态迁出，
  需先把 Runtime 值对该状态的依赖抽象成接口，留待阶段 3.4 或后续子阶段。
- IL 与字节码/VM 后端尚未拆出，阶段 3 不标记完成。
