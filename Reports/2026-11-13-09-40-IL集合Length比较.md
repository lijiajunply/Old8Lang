# IL 集合 Length 比较修复测试

测试日期：2026-11-13

## 修复范围

`List<T>.Length` 在 IL 模式映射为 CLR `ICollection.Count`。除发射代码外，静态类型推断也将其
识别为 `int`，使比较表达式采用正确的整数比较 IL。

## 回归用例

```old8
items <- {1, 2, 3}

func hasItems(values:list) -> bool {
    return values.Length > 0
}

Assert.True(items.Length > 0)
Assert.True(hasItems(items))
```
