## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `ImportStatement` | 从 Runtime 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间与构造方式不变 |
| 模块加载辅助 | 懒导入、选择导入、动态导入与 `ModuleSystemService` 静态实例移入 `ImportStatementRuntimeExtensions`（扩展方法） |
| 数据访问 | 内部字段改为公开只读属性 `ImportString`/`FromClause`/`Specifiers`/`ModuleAlias`/`IsLazy`/`IsSelective`/`DynamicModuleExpression`；既有 `Get*` 方法保留 |
| 消费者更新 | 解释器的导入执行/模块服务调用、字节码编译器的导入分支、测试与 Visitor 桩同步更新 |
| 生成代码 | Runtime 节点 50 → 49；遗留 partial 基线 8 → 7 |

行为保持：静态/懒/选择/动态导入与 `from ... import ...` 的解析、模块工厂选择、别名注册、
符号代理与错误位置均沿用原实现。
