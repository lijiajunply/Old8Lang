## 代码改进

### 1. LangValueType.cs
增加了对更多 List 类型的支持：
```csharp
List<string> a => new ListLangValue(a.Cast<object>().ToList()),
List<int> a => new ListLangValue(a.Cast<object>().ToList()),
List<double> a => new ListLangValue(a.Cast<object>().ToList()),
```

### 2. OS.cs
简化了平台检测逻辑，增加了对 macOS 的支持：
```csharp
if (RuntimeInformation.IsOSPlatform(OSPlatform.Windows))
{
    a.StartInfo.FileName = "cmd.exe";
}
else
{
    // Linux 和 macOS 都使用 bash
    a.StartInfo.FileName = "/bin/bash";
}
```
