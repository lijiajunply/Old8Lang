## 5. 关键问题和解决方案

### 5.1 问题 1: LangInterpreter API 使用错误

**问题描述**:
初次创建测试时使用了错误的 API 模式：
```csharp
var interpreter = new LangInterpreter(code);  // ❌
interpreter.Run();  // ❌
var manager = interpreter.GetGlobalManager();  // ❌
```

导致 64 个编译错误：
```
error CS1729: "LangInterpreter"不包含采用 1 个参数的构造函数
error CS1061: "LangInterpreter"未包含"Run"的定义
```

**解决方案**:
参考 `AssignmentTests.cs` 找到正确的 API 模式：
```csharp
var interpreter = new LangInterpreter();  // ✅
var ast = interpreter.Build(code);  // ✅
ast.Run(interpreter.Manager);  // ✅
var result = interpreter.Manager.GetValue(new LangId("name"));  // ✅
```

**修复操作**:
- 删除了错误的 `UnionTypesInterpreterTests.cs` 文件
- 使用正确的 API 模式重新创建文件

---

### 5.2 问题 2: Assert.Equal 类型不匹配

**问题描述**:
多个测试中出现类型不匹配错误：
```
error CS1503: 参数 2: 无法从"Old8Lang.AST.Expression.Value.StringLangValue"转换为"System.Collections.Generic.IAsyncEnumerable<char>?"
```

错误代码：
```csharp
Assert.Equal("hello", c.ToStr());  // ❌
```

**根本原因**:
`ToStr()` 方法返回的是 `StringLangValue` 对象，而不是 C# 的 `string` 类型。

**解决方案**:
改为先断言类型，再提取实际值进行比较：
```csharp
Assert.IsType<StringLangValue>(c);
Assert.Equal("hello", ((StringLangValue)c).Value);  // ✅
```

**修复位置**（共 9 处）:
- Line 41: `SimpleUnionTypeAssignment` 测试
- Line 74: `MultipleTypesUnionAssignment` 测试
- Line 97: `NullableUnionTypeNullAssignment` 测试
- Line 124: `NullableUnionTypeNonNullAssignment` 测试
- Line 154: `UnionTypeFunctionParameterWithInt` 测试
- Line 179: `UnionTypeFunctionParameterWithString` 测试
- Line 207-208: `MultipleUnionTypeParameters` 测试
- Line 270: `UnionTypeFunctionReturnString` 测试
- Line 317: `UnionTypeClassFieldAssignment` 测试
- Line 358: `UnionTypeClassFieldReassignment` 测试
- Line 415: `MemberTypeToUnionTypeCompatibility` 测试

### 5.3 问题 3: 运行时类型检查不完整

**问题描述**:
解释器测试失败，抛出 `TypeError`：
```
Old8Lang.Error.TypeError: 类型不兼容：期望 int|string，但得到 int
```

**根本原因**:
`VariateManager.ValidateTypeCompatibility()` 方法尚未完全实现联合类型的兼容性规则：
- 需要支持：`int` 兼容于 `int | string`
- 需要支持：`int | string` 兼容于 `int`（当实际值类型匹配时）
- 需要支持：可空联合类型与 `null` 的兼容性

**建议修复**:
在 `Old8Lang/Interpreter/VariateManager.cs` 中增强 `ValidateTypeCompatibility()` 方法，参考 `TypeAnnotationManager.ValidateParsedTypeCompatibility()` 的实现逻辑。
