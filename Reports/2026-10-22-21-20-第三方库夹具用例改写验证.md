## 1. 背景

该用例仍是早期写法：`var x = ...` 赋值、`Logger.debug(...)` 静态调用、`Math.*` / `String.*` / `Collection.*`
等旧 API。直接运行在解析阶段就失败（`表达式 'var' 不能作为独立语句出现`）。

## 2. 变更

| 文件 | 变更 |
|------|------|
| `tests/test_thirdparty.old8` | 按实际包 API 重写：`<-` 赋值、`PrintLine`、`LoggerClass(...)` 实例方法、`Http.Create(...)`、`SimpleLogger` / `SimpleMath` 函数 API |
| `packages/HttpClient/HttpClient.old8` | 内部 `Logger.Create("HttpClient")` → `LoggerClass("HttpClient")`（原写法在跨模块时解析到类而非实例） |
| `Old8Lang/ModuleSystem/Resolution/ModuleResolver.cs` | 第三方包搜索增加「项目根（`o8package.json` 所在目录）/packages」，使 `tests/`、`src/` 下的脚本也能导入项目本地包 |
| `ModuleResolver.cs` 错误提示 | 「当前目录的 packages/」→「项目根（`o8package.json` 所在目录）的 packages/」 |
| 编译器侧 `LazyImportSyntaxTest`、`UnifiedModuleArchitectureTests` | 临时文件从仓库内 `OldLib/temp` 迁到系统临时目录（补齐 P1 遗漏） |
| 解释器侧同名测试 | 临时子目录改为类名前缀，避免与编译器侧同名目录互串 |
