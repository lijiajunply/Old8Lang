# 阶段 3.13 异步函数体 IL 发射迁入 IL 后端

日期：2026-11-14 17:50  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3 的 IL 引擎余量。

## 改动

1. `AsyncFuncLangValue.GenerateMethodBody`（异步状态机启动代码，约 130 行 IL）从 Runtime
   改为 `Old8Lang.Compiler/Compilers/AsyncFuncLangValueIlCompilerExtensions.cs` 的扩展方法。
   Runtime 只保留共享开关 `IlCompilerOptions` 与 `AsyncStateMachineGenerator`。
2. `IlDisassembler` 从 Runtime 迁入 `Old8Lang.Compiler/Verification/`。
3. 删除 Runtime 的 `AsyncFuncInitRuntimeExtensions.GenerateAsyncMethodBody`，IL Visitor 直接调用
   `GetAsyncFuncValue().GenerateMethodBody(...)` 扩展方法。
4. Runtime 的 `Compiler/` 目录现在只剩共享编译契约：
   `LocalManager`、`GlobalVariableScope`、IL 生成缓存、`RuntimeGlobals`/常量注册表、
   `AssertHelper`/`ExceptionWrapper`、泛型特化与 `IlCompilerOptions`。

## 验证

构建（`/usr/local/share/dotnet/dotnet build Old8Lang.sln`）：0 错误。

| 测试组 | 结果 |
| --- | --- |
| Architecture | 61 通过 |
| VirtualMachine | 1083 通过 |
| Interpreter（排除 NetLibTests） | 1959 通过，1 跳过 |
| Compiler.Expressions | 179 通过，41 失败；与 HEAD 基线逐项一致 |
| Compiler.Async | 43 通过，65 失败，3 跳过；与 HEAD 基线完全一致 |

`Compiler.Async` 的失败集合在未改动 HEAD 上逐项复现（异步 IL 的既有缺陷已记录在 `Todo.md`），
未因本次迁移改变。

## 遗留

- `AsyncGeneration/AsyncStateMachineGenerator` 仍留在 Runtime（`LocalManager` 直接持有其类型），
  需要先抽象状态机生成契约才能迁出。
- 解释期作用域状态与运行时值 partial 同前；阶段 3 不标记完成。
