# 完善编译模式异步支持计划

## 1. 概述
目前Old8Lang的解释模式已经完整支持async/await，但编译模式下的异步支持还不完善。需要实现以下功能：
- async/await的IL生成
- Task类型的编译支持
- AsyncStateMachine生成

## 2. 实现步骤

### 2.1 实现Task类型的IL生成支持
- 修改`TaskLangValue.LoadIlValue`方法，使其能够生成正确的IL代码
- 支持Task类型的属性访问（IsCompleted、Status等）
- 支持Task类型的方法调用（Await、AwaitAsync等）

### 2.2 改进AwaitExpression的IL生成
- 修改`AwaitExpression.LoadIlValue`方法，实现真正的异步等待
- 生成调用Task.GetAwaiter()、Awaiter.IsCompleted和Awaiter.GetResult()的IL代码
- 支持异步状态机的切换

### 2.3 实现异步状态机生成
- 创建AsyncStateMachineGenerator类，用于生成异步状态机
- 支持异步函数的编译，生成包含状态机的IL代码
- 实现状态机的MoveNext方法，处理异步操作的不同阶段

### 2.4 修改AsyncFuncLangValue的IL生成
- 更新`AsyncFuncLangValue.LoadIlValue`方法，生成异步函数的IL代码
- 支持异步函数的参数传递和返回值处理
- 集成异步状态机生成

### 2.5 添加异步编译测试用例
- 创建测试用Old8Lang代码文件，测试async/await功能
- 验证编译模式下异步代码的正确性
- 确保与解释模式的行为一致

## 3. 核心实现细节

### 3.1 Task类型IL生成
- 直接使用.NET的Task类型作为底层实现
- 支持Task<T>和Task两种形式
- 实现Task的状态管理和结果获取

### 3.2 Await表达式编译
- 生成标准的async/await IL模式：
  1. 调用GetAwaiter()获取等待器
  2. 检查IsCompleted属性
  3. 如果已完成，直接调用GetResult()
  4. 如果未完成，保存当前状态，切换到状态机

### 3.3 异步状态机设计
- 状态机包含当前状态、任务等待器、局部变量等
- MoveNext方法处理状态转换
- 支持异常处理和取消操作

## 4. 预期效果
- 编译模式下能够正确处理async/await关键字
- 支持Task类型的声明、赋值和使用
- 异步函数能够生成正确的IL代码并执行
- 编译模式与解释模式的异步行为保持一致

- 创建各种异步场景的测试用例
- 测试简单异步函数调用
- 测试嵌套异步操作
- 测试异常处理和取消操作
- 测试Task组合方法（WhenAll、WhenAny等）
