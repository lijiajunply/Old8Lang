# Old8Lang 三个关键问题修复报告

修复日期：2025-12-12

## 概述

本次成功修复了 Old8Lang 解释器的三个关键问题，大幅提升了语言的易用性和功能完整性。

## 问题 1：嵌套索引访问 ✅ 已修复

### 问题描述
不支持 `array[0][0]` 这种链式索引访问，必须使用中间变量：
```old8
// 之前（不支持）
value <- nested[0][0]  // 报错：不支持类型 'ArrayLangValue' 的点操作

// 需要改为
row <- nested[0]
value <- row[0]
```

### 修复方案
在以下类中覆盖 `Dot` 方法以支持嵌套索引访问：
1. **ArrayLangValue** (`Old8Lang/AST/Expression/Value/ArrayLangValue.cs`)
2. **ListLangValue** (`Old8Lang/AST/Expression/Value/ListLangValue.cs`)
3. **DictionaryLangValue** (`Old8Lang/AST/Expression/Value/DictionaryLangValue.cs`)

### 实现细节
```csharp
// ArrayLangValue.cs - 新增 Dot 方法
public override LangValueType Dot(LangExpression dotExpression)
{
    // 如果是整数值，视为索引访问
    if (dotExpression is IntLangValue intValue)
    {
        return Get(intValue);
    }

    // 尝试运行表达式获取索引
    var tempManager = new LangParser.VariateManager();
    var result = dotExpression.Run(tempManager);

    if (result is IntLangValue idx)
    {
        return Get(idx);
    }

    return base.Dot(dotExpression);
}
```

### 测试验证
```old8

matrix <- [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
PrintLine("matrix[0][0] = " + matrix[0][0])  // 输出：1
PrintLine("matrix[1][1] = " + matrix[1][1])  // 输出：5

// 三维数组

// 数组嵌套字典

    {"name": "Alice", "age": 20},
    {"name": "Bob", "age": 21}
]
PrintLine(students[0]["name"])  // 输出：Alice

// 字典嵌套数组

PrintLine(classes["math"][0])  // 输出：90

// 多层嵌套
complex <- {"users": [{"tags": ["admin", "active"]}]}
PrintLine(complex["users"][0]["tags"][0])  // 输出：admin
```

## 问题 2：Json/ToObj 函数限制 ✅ 已修复

### 问题描述
`Json()` 函数只支持 `AnyValue` 类型，不支持字典和数组的直接序列化：
```old8
dict <- {"name": "Alice", "age": 30}
jsonStr <- Json(dict)  // 报错：类型不匹配，期望 AnyValue
```

### 修复方案
扩展 `Instance.cs` 中的 `Json` 函数处理，支持多种类型：
1. **DictionaryLangValue** - 字典转 JSON
2. **ArrayLangValue** - 数组转 JSON
3. **ListLangValue** - 列表转 JSON
4. **AnyLangValue** - 保留原有支持

### 实现细节
```csharp
// Instance.cs - 修改 Json 函数
case "Json" or "json":
{
    switch (results[0])
    {
        case AnyLangValue jsonAnyValue:
            return jsonAnyValue.ToJson();

        case DictionaryLangValue dictValue:
        {
            var dict = new Dictionary<string, object>();
            foreach (var (key, value) in dictValue.Value)
            {
                var keyStr = key.ToDisplayString();
                dict[keyStr] = value.GetValue();
            }
            var jsonStr = System.Text.Json.JsonSerializer.Serialize(dict);
            return new StringLangValue(jsonStr);
        }

        case ArrayLangValue arrayValue:
        {
            var list = arrayValue.GetItems().Select(item => item.GetValue()).ToList();
            var jsonStr = System.Text.Json.JsonSerializer.Serialize(list);
            return new StringLangValue(jsonStr);
        }

        case ListLangValue listValue:
        {
            var list = listValue.GetItems().Select(item => item.GetValue()).ToList();
            var jsonStr = System.Text.Json.JsonSerializer.Serialize(list);
            return new StringLangValue(jsonStr);
        }

        default:
            throw new TypeError(this, "AnyValue/DictionaryValue/ArrayValue/ListValue",
                               results[0].GetType().Name);
    }
}
```

### 测试验证

## 问题 3：数组比较 ✅ 已修复

### 问题描述
`Assert` 函数无法比较两个数组，即使内容相同也会失败：
```old8
arr1 <- [1, 2, 3]
arr2 <- [1, 2, 3]
Assert(arr1, arr2)  // 失败：比较的是引用而非内容
```

### 修复方案
在以下类中覆盖 `Equal` 方法，实现深度内容比较：
1. **ArrayLangValue** - 数组深度比较
2. **ListLangValue** - 列表深度比较
3. **DictionaryLangValue** - 字典深度比较

### 实现细节
```csharp
// ArrayLangValue.cs - 新增 Equal 方法
public override bool Equal(LangValueType? otherValueType)
{
    if (otherValueType is not ArrayLangValue otherArray)
        return false;

    // 比较长度
    if (RunResult.Length != otherArray.RunResult.Length)
        return false;

    // 逐个比较元素（递归比较）
    for (int i = 0; i < RunResult.Length; i++)
    {
        if (!RunResult[i].Equal(otherArray.RunResult[i]))
            return false;
    }

    return true;
}

// ListLangValue.cs - 类似实现
public override bool Equal(LangValueType? otherValueType)
{
    if (otherValueType is not ListLangValue otherList)
        return false;

    if (Values.Count != otherList.Values.Count)
        return false;

    for (int i = 0; i < Values.Count; i++)
    {
        if (!Values[i].Equal(otherList.Values[i]))
            return false;
    }

    return true;
}

// DictionaryLangValue.cs - 键值对比较
public override bool Equal(LangValueType? otherValueType)
{
    if (otherValueType is not DictionaryLangValue otherDict)
        return false;

    if (Value.Count != otherDict.Value.Count)
        return false;

    foreach (var (key, value) in Value)
    {
        var matchingPair = otherDict.Value.FirstOrDefault(p => p.Key.Equal(key));

        if (matchingPair.Key == null || !value.Equal(matchingPair.Value))
            return false;
    }

    return true;
}
```

## 性能影响

### 时间复杂度
- **嵌套索引访问**: O(n)，其中 n 是嵌套层级
- **Json 序列化**: O(m)，其中 m 是元素总数
- **深度比较**: O(m)，其中 m 是元素总数（递归比较）

### 空间复杂度
- **嵌套索引访问**: O(1)，使用临时 VariateManager
- **Json 序列化**: O(m)，需要构建中间数据结构
- **深度比较**: O(1)，原地比较
