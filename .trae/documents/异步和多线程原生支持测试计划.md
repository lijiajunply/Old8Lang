# 异步和多线程原生支持测试计划

## 测试目标

编写测试用例，验证 Old8Lang 原生支持的异步和多线程功能的正确性和可靠性。

## 测试结构

创建两个新的测试文件：

1. `AsyncNativeTests.cs` - 测试 Old8Lang 原生异步功能
2. `ThreadNativeTests.cs` - 测试 Old8Lang 原生多线程功能

## 测试内容

### 1. 异步功能测试

- **基本异步函数执行**：测试 async func 的定义和调用
- **异步函数参数传递**：测试带参数的异步函数
- **异步函数返回值**：测试异步函数的返回值处理
- **嵌套异步调用**：测试异步函数内部使用 await
- **异步异常处理**：测试异步函数抛出异常的情况
- **异步取消机制**：测试 CancellationToken 的使用
- **异步任务组合**：测试 Task.WhenAll 和 Task.WhenAny
- **异步延迟**：测试 Task.Delay
- **异步 Lambda**：测试异步 Lambda 表达式

### 2. 多线程功能测试

- **基本线程创建**：测试 Thread 类的创建和启动
- **线程参数传递**：测试带参数的线程
- **线程结果获取**：测试线程执行结果的获取
- **线程等待**：测试 Thread.Join
- **线程异常处理**：测试线程抛出异常的情况
- **线程取消**：测试线程的取消机制
- **多线程同步**：测试线程安全操作
- **线程组合**：测试 Thread.WhenAll 和 Thread.WhenAny
- **线程延迟**：测试 Thread.Delay

## 测试方法

1. 使用 Xunit 测试框架
2. 编写 Old8Lang 代码作为测试用例
3. 使用 LangInterpreter 执行测试代码
4. 验证执行结果是否符合预期
5. 测试异常情况和边界条件

## 测试文件位置

- `Old8Lang.Tests/Language/AsyncNativeTests.cs`
- `Old8Lang.Tests/Language/ThreadNativeTests.cs`

## 测试用例设计

每个测试用例将：
1. 编写 Old8Lang 代码测试特定功能
2. 使用 Interpreter 执行代码
3. 验证输出结果或异常情况
4. 确保测试覆盖正常和异常情况

## 依赖关系

- 依赖 Old8Lang 解释器
- 依赖 Xunit 测试框架
- 依赖 Old8Lang 核心功能模块

## 预期结果

所有测试用例通过，验证 Old8Lang 原生支持的异步和多线程功能工作正常。
