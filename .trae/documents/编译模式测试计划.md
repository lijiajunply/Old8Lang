# 编译模式测试计划

## 测试目标
对Old8Lang的编译模式进行全面测试，验证其正确性和性能。

## 测试内容
1. 测试CompilerTests目录下的所有.old8文件
2. 验证编译模式下各种语法特性的正确性
3. 记录编译和执行时间，评估性能

## 测试步骤
1. 查看CompilerTests目录下的测试文件列表
2. 使用Old8Lang.App的编译模式（-c参数）依次测试每个文件
3. 记录测试结果和性能数据
4. 生成测试报告

## 测试命令
```bash
# 测试单个文件
dotnet run --project Old8Lang.App -- -c <path-to-test-file.old8>

# 批量测试所有文件
for file in CompilerTests/*.old8; do
echo "Testing $file"
dotnet run --project Old8Lang.App -- -c "$file"
done
```

## 测试报告
将生成包含以下内容的测试报告：
- 测试文件列表
- 每个文件的测试结果（成功/失败）
- 编译和执行时间
- 错误信息（如果有）
- 性能统计

## 预期结果
所有测试文件在编译模式下都能正常执行，没有语法错误或运行时错误。
