## 最终结构

```text
Old8Lang.App / LanguageServer / Benchmarks / Tests
                      ↓
                    Hosting（显式注册解释 / IL / VM 后端）
        ↙                 ↓                  ↘
Old8Lang.Interpreter  Old8Lang.Compiler  Old8Lang.VirtualMachine
   Visitor               Visitor              Visitor
   LangInterpreter       Compiler 驱动         VirtualMachine 引擎
   解释器调试器           IL 运算/LINQ/异步     BytecodeCompiler / 模块加载
        ↘                 ↓                  ↙  VM 调试、分析、Interop
                    Old8Lang.Runtime
  运行时值、内置函数、模块/类型系统、字节码格式（BytecodeFile/Core/Metadata/Closures）
  共享契约：RuntimeVisitors、ILangInterpreter、IVirtualMachine、IBytecodeCompiler、
            IAsyncStateMachineGenerator、IlCompilerOptions
  共享执行状态：VariateManager/ScopeLayer、LocalManager/类型推断/泛型特化
                      ↓
  Core / Concurrency / Modules.Abstractions / Observability / ProjectSystem / Syntax
```

三个后端程序集互不引用，只引用 `Old8Lang.Runtime`；Runtime 不引用任何后端程序集。
`BackendAssemblyBoundaryTests`（62 项架构测试的一部分）验证程序集引用图、契约归属、
`LangInterpreter`/`VirtualMachine`/`BytecodeCompiler`/`AsyncStateMachineGenerator` 的程序集位置，
以及 Runtime 源码不再直接构造三种 Visitor。

## 共享运行时边界

`VariateManager`/`ScopeLayer`（解释期状态）与 `LocalManager`/类型推断/泛型特化（IL 编译状态）
仍位于 Runtime。它们是运行时值、内置函数与三个后端共同依赖的共享执行模型，不属于任何
后端对另一后端的反向依赖；spec 第 2 条要求的是「共享运行时值和语法节点的归属有明确边界」，
该边界由 `BackendAssemblyBoundaryTests` 与本文固定。若将来要把这些状态也迁出，需要先把
运行时值对它们的依赖抽象为接口，属于新的独立目标，不阻塞阶段 3 的验收。
