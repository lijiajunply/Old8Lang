# 阶段 2「块语句节点迁移」测试报告

日期：2026-11-14 14:08
范围：`Docs/architecture-migration/plan.md` §2 的增量：`BlockStatement` 迁移
状态：本批完成；阶段 2 整体未完成（解析器、剩余声明/控制流节点、运行时值仍待拆分）。

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `BlockStatement` | 从 `Old8Lang.Runtime/AST/Statement` 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变；`Accept` 改走 Syntax `IVisitor` |
| 块内分类 | 新增语法层标记接口 `IBlockDeclaration`（`FuncInit`、`ClassInit`、`AsyncFuncInit`、`NativeStatement`、`ExternStatement`）与 `IBlockImportDeclaration`（`ImportStatement`，保留 `IsDynamicImport`）；块构造不再按具体 Runtime 节点类型分支 |
| 执行/编译辅助 | `ExecuteDeclarations`、`ExecuteModule`、`GenerateImportIl`、`ToAnyData`、`ToStaticData`、`GetTuple`、`IsFunction` 移入 Runtime 的 `BlockStatementRuntimeExtensions`；五个公开方法保持可调用（扩展方法写法不变），`GetTuple`/`IsFunction` 收窄为 private（全仓无其他调用方） |
| 生成代码 | `IVisitor` 新增 `VisitBlockStatement`；Runtime 生成节点 75；`BlockStatement.Accept.generated.cs` 移入 `backups/trash-2026-11-14/`（仓库外废纸篓在本次会话中不可写，改用工作区备份目录，已加入 `.git/info/exclude`） |
| 测试 | 新增 `SyntaxStatementBlockTests` 6 项；语法程序集归属断言与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 27 → 26 |

行为保持：声明/导入分类集合与顺序不变；动态导入仍在普通语句流；遇到 `ReturnStatement` 后停止收集的既有语义不变；类成员字典的函数重载合并逻辑原样保留（重复分支合并为 `AddMember`，判定顺序一致）。
