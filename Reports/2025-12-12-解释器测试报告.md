## 已发现的问题和限制

### 1. 嵌套索引访问
**问题**: 不支持 `array[0][0]` 这种链式索引访问
**解决方案**: 使用中间变量
```old8
// 不支持
value <- nested[0][0]

// 需要改为
row <- nested[0]
value <- row[0]
```

### 2. Json/ToObj 函数限制
**问题**: `Json()` 函数只支持 AnyValue 类型，不支持字典和数组
**状态**: 暂时跳过相关测试

### 3. 数组比较
**问题**: Assert 函数无法比较两个数组（即使内容相同）
**原因**: 数组是引用类型，比较的是引用而非内容

### 4. Math 库导入
**问题**: Math.old8 中的导入语法 `[import "Old8LangLib" Math] => "System"` 不被支持
**解决方案**: Math 是内置运算，无需导入
