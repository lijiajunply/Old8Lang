# 多线程支持实现计划

## 1. 概述

本计划旨在为 Old8Lang 添加多线程支持，允许用户通过 `spawn` 函数创建新线程，并通过 `Join` 方法等待线程完成并获取返回值。

## 2. 实现方案

### 2.1 扩展 AsyncLib 类

在现有的 `AsyncLib` 类中添加线程管理功能，类似于现有的 Mutex 和 Semaphore 管理：

- 添加线程存储字典，用于管理创建的线程
- 添加线程结果存储字典，用于存储线程的返回值
- 添加线程计数器，用于生成唯一的线程 ID

### 2.2 实现 spawn 函数

添加 `spawn` 方法，支持两种形式的调用：

1. 直接传递 lambda 表达式：`spawn(() -> { ... })`
2. 传递函数和参数：`spawn(func, arg1, arg2, ...)`

### 2.3 实现 Thread 类

创建 `Thread` 类来封装线程操作，包括：

- 线程 ID
- 线程状态
- `Join` 方法，用于等待线程完成并获取返回值

### 2.4 实现 Join 方法

添加 `Join` 方法，用于等待线程完成并获取返回值：

- 支持等待指定时间
- 支持获取线程执行结果

## 5. 预期效果

用户可以使用以下语法创建和使用线程：

```old8
// 1. 基础线程创建和使用
thread <- spawn(() -> {
    PrintLine("在新线程中执行")
})
result <- thread.Join()  // 等待线程完成，获取返回值

// 2. 带参数的线程函数
threadFunc <- (x:int, y:int) -> int {
    return x + y
}
thread <- spawn(threadFunc, 10, 20)
result:int <- thread.Join()
```
