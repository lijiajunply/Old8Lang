###  1. ✅ AssertionError - Assert 函数

**应用位置**: `Old8Lang/AST/Expression/Value/Instance.cs` (第 171-181 行)

**修改内容**:
```csharp
case "Assert" or "assert":
{
    var value = results[0].Run(manager);
```

### 3. ✅ FileNotFoundException - 文件操作

**应用位置**: `Old8LangLib/FileLib.cs` (第 8-62 行)

**修改内容**:

#### FileRead
```csharp
public static string FileRead(string path)
{
    if (!File.Exists(path))
    {
        throw new FileNotFoundException($"文件不存在: '{path}'", path);
    }
    return File.ReadAllText(path);
}
```

#### FileReadLines
```csharp
public static string[] FileReadLines(string path)
{
    if (!File.Exists(path))
    {
        throw new FileNotFoundException($"文件不存在: '{path}'", path);
    }
    return File.ReadLines(path).ToArray();
}
```

#### CopyFile
```csharp
public static void CopyFile(string filepath, string copyPath)
{
    if (!File.Exists(filepath))
    {
        throw new FileNotFoundException($"源文件不存在: '{filepath}'", filepath);
    }
    File.Copy(filepath, copyPath, true);
}
```

## 二、架构设计决策

### 异常类型选择策略

我们采用了**分层异常处理策略**：

#### 层次 1: Old8Lang 核心 (Old8Lang 项目)
- 使用自定义错误类型: `AssertionError`, `ValueError`, `FileNotFoundError` 等
- 提供统一的错误格式和用户体验
- 包含源代码位置、上下文和建议信息

#### 层次 2: 原生库 (Old8LangLib 项目)
- 使用标准 .NET 异常: `ArgumentException`, `FileNotFoundException` 等
- 保持库的独立性，不依赖 Old8Lang 核心
- 未来可以通过异常转换层桥接两个层次

### 架构优势

1. **解耦性**: Old8LangLib 可以独立使用，不依赖 Old8Lang 核心
2. **标准兼容**: 使用标准 .NET 异常，与 C# 生态系统兼容
3. **扩展性**: 可以轻松添加异常转换层，将 .NET 异常映射到 Old8Lang 异常
4. **清晰性**: 错误来源清晰（核心 vs 库）
