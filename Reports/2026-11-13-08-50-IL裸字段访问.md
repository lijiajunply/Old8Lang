# IL 裸字段访问修复测试

测试日期：2026-11-13

## 修复范围

类实例方法中，未带 `this.` 前缀的字段读取会正确推断为字段的 CLR 类型。此前字段值虽已用
`ldfld` 加载，但其表达式类型被标为 `object`，导致 `return` 代码生成重复拆箱并在运行时失败。

## 回归用例

`Class_MethodCanReadBareField_CompilesAndExecutes` 编译并执行以下核心场景：

```old8
class Counter {
    public value:int <- 5

    func get() -> int {
        return value
    }
}

counter <- Counter()
Assert.Equal(5, counter.get())
```
