# 接口语法实现计划

## 1. 概述

本计划旨在为 Old8Lang 添加完整的接口语法支持，包括接口声明和类实现接口的功能。

## 2. 语法定义

需要添加的接口语法如下：

```
interface IDrawable {
    func draw() -> void
}

class Circle implements IDrawable {
    func draw() -> void {
        PrintLine("Drawing circle")
    }
}
```

## 3. 实现步骤

### 3.1 添加关键字

在 `LangTokenType.cs` 文件中添加以下关键字：
- `Interface`：用于接口声明
- `Implements`：用于类实现接口

同时在 `KeywordType` 枚举中添加对应的关键字。

### 3.2 修改 EBNF 语法定义

在 `Old8Lang.ebnf` 文件中添加以下语法规则：

1. 在 `statement` 规则中添加 `interfaceDeclaration`
2. 添加 `interfaceDeclaration` 规则
3. 修改 `classDeclaration` 规则，添加 `implements` 子句
4. 添加 `interfaceBlock` 规则

### 3.3 修改解析器

#### 3.3.1 StatementParser.cs

- 在 `ParseStatement` 方法中添加对 `interface` 关键字的处理
- 调用 `classParser.ParseInterfaceDeclaration()` 方法解析接口声明

#### 3.3.2 ClassParser.cs

- 添加 `ParseInterfaceDeclaration()` 方法，用于解析接口声明
- 修改 `ParseClassDeclaration()` 方法，添加对 `implements` 子句的处理
- 支持类实现多个接口，语法为 `class Name implements Interface1, Interface2 { ... }`

### 3.4 修改 AST 相关文件

- 添加 `InterfaceInit` 类，用于表示接口声明的 AST 节点
- 修改 `ClassInit` 类，添加 `Implements` 属性，用于存储实现的接口列表
- 修改 `TypeTemplate` 类，添加接口相关的属性和方法

### 3.5 修改解释器和编译器

- 修改解释器，支持接口的解释执行
- 修改编译器，支持接口的中间代码生成
- 添加接口类型检查，确保实现类正确实现了接口的所有方法

### 3.6 编写测试用例

- 在 `SyntaxTests` 目录下添加接口语法测试用例
- 在 `InterpreterTests` 目录下添加接口解释模式测试用例
- 在 `CompilerTests` 目录下添加接口编译模式测试用例

## 4. 预期效果

- 支持接口声明和类实现接口的语法
- 接口中的方法只能声明，不能实现
- 类必须实现接口中的所有方法
- 支持多接口实现
- 接口支持访问修饰符
- 能够在解释模式和编译模式下正确运行

## 5. 注意事项

- 接口中的方法不能有实现体
- 接口不能继承其他类，只能继承其他接口（可选支持）
- 实现接口的类必须实现接口中的所有方法，包括方法签名和返回类型
- 接口支持访问修饰符，但默认是 public
- 接口可以包含属性声明（可选支持）

## 6. 测试用例

```old8
// 接口声明
interface IDrawable {
    func draw() -> void
}

// 类实现接口
class Circle implements IDrawable {
    func draw() -> void {
        PrintLine("Drawing circle")
    }
}

// 多接口实现
interface IResizable {
    func resize(width: int, height: int) -> void
}

class Rectangle implements IDrawable, IResizable {
    func draw() -> void {
        PrintLine("Drawing rectangle")
    }
    
    func resize(width: int, height: int) -> void {
        PrintLine("Resizing rectangle to " + width + "x" + height)
    }
}

// 测试代码
var circle = Circle()
circle.draw()

var rectangle = Rectangle()
rectangle.draw()
rectangle.resize(10, 20)
```
