# Old8Lang 语法修复计划

## 1. 核心语法修复

### 1.1 自增自减运算符支持

**问题**：当前解析器只支持简单的 `i++` 和 `i--` 作为单独的语句，不支持在表达式中使用前置或后置自增自减。

**修复方案**：
1. 在 `ParseExpression` 方法中添加对前置自增自减的支持
2. 在 `ParsePrimary` 方法中添加对后置自增自减的支持
3. 更新 `OperationType` 枚举以支持自增自减操作
4. 修复文件：`LangParser.cs`

### 1.2 null 关键字支持

**问题**：当前解析器没有处理 `null` 关键字作为合法表达式值的逻辑。

**修复方案**：
1. 在 `ParsePrimary` 方法中添加对 `null` 关键字的支持
2. 创建对应的 `NullValue` 类来表示 null 值
3. 更新 `OperationType` 枚举以支持 null 操作
4. 修复文件：`LangParser.cs`、`ValueType.cs`

## 2. 高级语法特性

### 2.1 复杂类语法

**问题**：当前类字段不支持类型注解。

**修复方案**：
1. 更新 `set` 规则以支持类型注解：`identifier ( ":" identifier )? "<-" expression`
2. 确保 `ParseSet` 方法正确处理类内字段的类型注解
3. 修复文件：`LangParser.cs`

### 2.2 异常处理语法

**问题**：当前 `try-catch-finally` 语句的解析实现可能不完整。

**修复方案**：
1. 检查并完善 `ParseTryStatement` 方法
2. 确保支持嵌套的 `try-catch` 结构
3. 添加对异常抛出（如果支持）的解析
4. 修复文件：`LangParser.cs`

### 2.3 表达式解析

**问题**：赋值表达式中的语法错误需要修复。

**修复方案**：
1. 检查并完善 `ParseExpression` 方法
2. 确保支持更复杂的表达式嵌套
3. 修复文件：`LangParser.cs`

## 3. 特殊语法支持

### 3.1 导入语句优化

**问题**：导入语句中可能存在空引用错误。

**修复方案**：
1. 检查并完善 `ParseImportStatement` 方法
2. 确保处理各种导入场景
3. 修复文件：`LangParser.cs`

### 3.2 字符串模板增强

**问题**：复杂模板中的解析错误需要修复。

**修复方案**：
1. 检查并完善 `ParseStringTree` 方法
2. 确保支持更复杂的表达式插值
3. 修复文件：`LangParser.cs`

### 3.3 范围表达式优化

**问题**：范围表达式中的模板解析错误需要修复。

**修复方案**：
1. 检查并完善 `ParseArrayOrRange` 方法
2. 确保支持更复杂的范围使用场景
3. 修复文件：`LangParser.cs`

## 修复优先级

1. **null 关键字支持**（最高优先级，影响其他功能）
2. **自增自减运算符支持**（高优先级，常用语法）
3. **异常处理语法**（中优先级，重要的错误处理机制）
4. **复杂类语法**（中优先级，类字段类型注解）
5. **表达式解析**（中优先级，基础语法）
6. **导入语句优化**（低优先级，已有基础实现）
7. **字符串模板增强**（低优先级，已有基础实现）
8. **范围表达式优化**（低优先级，已有基础实现）

## 修复步骤

1. **第一步**：添加 `NullValue` 类，支持 null 关键字
2. **第二步**：完善自增自减运算符的解析
3. **第三步**：完善异常处理语法的解析
4. **第四步**：添加类字段类型注解支持
