# 文档契约: API 文档格式

**用途**: 标准化 API 参考文档的格式

---

## 标准模板

```markdown
### [函数名称]

**签名**: `function_name(param1: type1, param2: type2) -> return_type`

**功能**: [一句话描述函数功能]

**参数**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| param1 | type1 | [参数说明] |
| param2 | type2 | [参数说明] |

**返回值**: [返回值类型和说明]

**模式支持**: ✅ 解释模式 | ✅ 编译模式 | ✅ VM 模式

**示例**:
```old8lang
// 示例代码
[可运行的示例代码]
```

**输出**:
```
[预期输出]
```

**注意事项**: [可选，特殊说明或注意事项]
```

---

## 使用规则

### 1. 函数签名

- 使用代码格式 (`` ` ``)
- 包含所有参数和返回类型
- 参数类型使用 Old8Lang 类型系统

### 2. 参数表格

- 使用 Markdown 表格
- 列: 参数名 | 类型 | 说明
- 每个参数一行

### 3. 模式支持

- 使用 ✅ 表示支持
- 使用 ❌ 表示不支持
- 格式: `✅ 解释模式 | ❌ 编译模式 | ✅ VM 模式`

### 4. 示例代码

- 使用 `old8lang` 语言标注
- 包含注释说明关键步骤
- 代码必须可运行
- 提供预期输出

---

## 完整示例

```markdown
### sqrt

**签名**: `sqrt(x: number) -> number`

**功能**: 计算数字的平方根

**参数**:

| 参数名 | 类型 | 说明 |
|--------|------|------|
| x | number | 要计算平方根的数字（必须非负） |

**返回值**: number - 输入数字的平方根

**模式支持**: ✅ 解释模式 | ✅ 编译模式 | ✅ VM 模式

**示例**:
```old8lang
import "Math"

// 计算 16 的平方根
let result = Math.sqrt(16)
print(result)  // 输出: 4

// 计算 2 的平方根
let result2 = Math.sqrt(2)
print(result2)  // 输出: 1.4142135623730951
```

**输出**:
```
4
1.4142135623730951
```

**注意事项**: 如果输入负数，将抛出异常
```
