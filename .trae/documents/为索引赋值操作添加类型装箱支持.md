# 实现计划：为索引赋值操作添加类型装箱支持

## 1. 需求分析
为索引赋值操作（如 `array[index] = value`）添加类型装箱支持，当通过索引进行赋值时，自动对赋值的值执行类型装箱操作，根据数组声明的元素类型或上下文推断的目标类型进行转换。

## 2. 实现范围
- 解释模式下的索引赋值
- 编译模式下的索引赋值
- 支持不同数据类型（基本类型、自定义类型等）
- 类型检查和错误处理

## 3. 具体实现步骤

### 3.1 解释模式实现

#### 3.1.1 修改 `ListLangValue.Set` 方法
- 添加类型装箱逻辑，根据列表元素类型对赋值的值进行转换
- 实现不同类型之间的转换逻辑
- 添加类型不匹配的错误处理

#### 3.1.2 修改 `ArrayLangValue.Set` 方法
- 添加类型装箱逻辑，根据数组元素类型对赋值的值进行转换
- 实现不同类型之间的转换逻辑
- 添加类型不匹配的错误处理

### 3.2 编译模式实现

#### 3.2.1 修改 `SetStatement.GenerateIl` 方法
- 在索引赋值部分添加类型装箱支持
- 对于数组索引赋值，根据元素类型添加装箱指令
- 对于泛型列表索引赋值，根据列表的元素类型添加装箱指令
- 对于字典索引赋值，确保键值对都正确装箱

### 3.3 类型转换逻辑

#### 3.3.1 基本类型转换
- 实现基本类型之间的转换（int ↔ double, int ↔ string 等）
- 确保转换的安全性和正确性

#### 3.3.2 引用类型转换
- 实现引用类型之间的转换
- 处理自定义类型的转换

### 3.4 错误处理

#### 3.4.1 类型不匹配处理
- 添加类型不匹配时的详细错误信息
- 确保错误信息清晰易懂

#### 3.4.2 边界情况处理
- 处理空集合的情况
- 处理索引越界的情况
