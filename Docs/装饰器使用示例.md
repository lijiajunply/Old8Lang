# Old8Lang 装饰器使用示例

## 1. 基本装饰器

### 1.1 简单装饰器（返回原函数）

```old8
func identity(f) {
    PrintLine("装饰器被调用了！")
    return f
}

@identity
func myFunc(x:int) -> int {
    return x * 2
}

result <- myFunc(5)  // 输出: "装饰器被调用了！" 然后返回 10
```

### 1.2 日志装饰器

```old8
func log(f) {
    PrintLine("注册函数: " + f.Id.IdName)
    return f
}

@log
func add(a:int, b:int) -> int {
    return a + b
}
```

## 2. 带参数的装饰器

### 2.1 重复执行装饰器

```old8
func repeat(times) {
    PrintLine("设置重复次数: " + times.ToStr())
    return (f) -> {
        PrintLine("包装器被创建")
        return f
    }
}

@repeat(times: 3)
func greet(name:string) -> void {
    PrintLine("Hello, " + name)
}
```

### 2.2 缓存装饰器（概念示例）

```old8
func cache(timeout) {
    return (f) -> {
        // 这里可以实现缓存逻辑
        // 实际使用时需要处理闭包捕获
        return f
    }
}

@cache(timeout: 60)
func expensiveOperation(n:int) -> int {
    return n * n
}
```

## 3. 多个装饰器

### 3.1 装饰器堆叠

```old8
func decorator1(f) {
    PrintLine("decorator1 被调用")
    return f
}

func decorator2(f) {
    PrintLine("decorator2 被调用")
    return f
}

func decorator3(f) {
    PrintLine("decorator3 被调用")
    return f
}

@decorator1
@decorator2
@decorator3
func myFunc(x:int) -> int {
    return x
}

// 输出顺序：
// decorator3 被调用
// decorator2 被调用
// decorator1 被调用
```

### 3.2 应用顺序说明

装饰器从**下到上**依次应用（最接近函数的装饰器最先应用）：

```old8
@outer
@middle
@inner
func f() { }

// 等价于：
// temp1 = inner(f)
// temp2 = middle(temp1)
// final = outer(temp2)
```

## 6. 注意事项

### 6.1 装饰器函数签名

**无参数装饰器**：
```old8
func decorator(targetFunc) {
    // targetFunc 是被装饰的函数
    return targetFunc  // 必须返回一个函数
}
```

**带参数装饰器**（柯里化）：
```old8
func decorator(arg1, arg2) {
    return (targetFunc) -> {
        // 可以使用 arg1, arg2 和 targetFunc
        return targetFunc  // 必须返回一个函数
    }
}
```

### 6.2 装饰器必须返回函数

装饰器必须返回一个 `FuncLangValue` 类型的函数，否则会抛出错误：

```old8
func badDecorator(f) {
    return 123  // ❌ 错误：必须返回函数
}

func goodDecorator(f) {
    return f    // ✅ 正确：返回函数
}
```

### 6.3 装饰器定义顺序

装饰器函数必须在使用之前定义：

```old8
// ✅ 正确：先定义装饰器
func log(f) {
    return f
}

@log
func myFunc() { }

// ❌ 错误：装饰器未定义
@undefined
func myFunc() { }
```

## 7. 已知限制

1. **编译器模式**: 装饰器在编译器模式（`-c`）下的支持需要进一步完善
2. **闭包捕获**: Lambda 闭包捕获装饰器参数的场景需要特殊处理
3. **类型推断**: 装饰器可能改变函数签名，类型推断需要额外处理
