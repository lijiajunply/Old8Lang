## 代码示例

### 基础用法

```old8
// 定义可空泛型类
class Box<T?> {
    value: T?

    func init(v: T?) {
        this.value <- v
    }

    func getValue() -> T? {
        return this.value
    }

    func hasValue() -> bool {
        return this.value != null
    }
}

// 使用
box1 <- new Box(123)      // T? 推断为 int?
box2 <- new Box(null)     // T? 允许 null 值
```

### 泛型函数

```old8
func identity<T?>(value: T?) -> T? {
    return value
}

result1 <- identity<int>(456)    // 返回 456
result2 <- identity<int>(null)   // 返回 null
```

### 混合类型参数

```old8
class Container<T, U?> {
    required: T    // 非可空类型
    optional: U?   // 可空类型

    func init(r: T, o: U?) {
        this.required <- r
        this.optional <- o
    }
}

container <- new Container(100, "text")
container2 <- new Container(200, null)  // U? 可以是 null
```

### 带约束的可空类型

```old8
class OptionalValue<T?: IComparable> {
    data: T?

    func init(d: T?) {
        this.data <- d
    }

    func hasValue() -> bool {
        return this.data != null
    }
}
```

## 技术要点

### 1. 语法解析流程

```

  ↓
检测 Identifier token "T"
  ↓
检测 Question token "?"
  ↓
设置 isNullable = true
  ↓
创建 GenericParameter(name, constraints, position, isNullable)
```
