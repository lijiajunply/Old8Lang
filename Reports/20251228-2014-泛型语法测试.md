## 修复的关键问题

### 问题：带修饰符的泛型字段解析失败
**症状**:
- `items:List<int>` 解析成功（无修饰符）
- `private items:List<int>` 解析失败（有修饰符）
- 错误信息：`无法识别的主表达式类型 'LessThan'`

**根本原因**:
ClassParser 的 `ParseFieldDeclarationList` 方法在解析类型注解时，只处理了简单标识符和可空类型（`?`），没有处理泛型类型（`<...>`）。

**解决方案**:
1. 在 `ClassParser.ParseFieldDeclarationList` 方法中添加泛型类型检测：
```csharp
// 检查是否为泛型类型（例如 "List<int>"）
if (CurrentToken.Type == LangTokenType.LessThan)
{
    typeAnnotation += ParseGenericTypeAnnotation();
}
```

2. 添加 `ParseGenericTypeAnnotation` 方法到 ClassParser，支持递归解析嵌套泛型。

**修改文件**:
- `Old8Lang/LangParser/Parsers/ClassParser.cs` (lines 418-428, lines 666-712)
