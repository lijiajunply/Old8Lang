# 编译模式测试计划

## 测试目标
验证 Old8Lang 编译模式的正确性，确保各种语法结构在编译模式下能正常工作，特别是类型假注功能。

## 测试文件创建
已创建以下测试文件，放在 `CompilerTests` 目录下：

1. **01_basic_types_expressions.old8**
   - 测试各种基本数据类型（int、double、string、bool、char）
   - 测试数组、字典等复合类型
   - 测试算术、比较、逻辑表达式
   - 测试类型转换和三元表达式
   - 所有变量均使用类型假注

2. **02_control_flow.old8**
   - 测试 if-elif-else 语句
   - 测试 for 循环和 while 循环
   - 测试 for-in 循环（数组和字典）
   - 测试 switch 语句
   - 测试嵌套控制流
   - 所有变量均使用类型假注

3. **03_functions_classes.old8**
   - 测试多种函数声明形式
   - 测试函数调用和返回值
   - 测试 Lambda 表达式
   - 测试类声明、实例化和方法调用
   - 测试静态方法
   - 所有变量和参数均使用类型假注

4. **04_exception_special_syntax.old8**
   - 测试 try-catch-finally 异常处理
   - 测试 throw 语句
   - 测试字符串模板
   - 测试列表推导式
   - 测试范围表达式和元组
   - 所有变量均使用类型假注

## 测试执行
使用以下命令运行测试：

```bash
# 编译模式测试
dotnet run --project Old8Lang.App -- -c <path-to-test-file.old8>
```

将逐个运行四个测试文件，验证编译模式的正确性。

## 测试验证
- 检查编译是否成功
- 检查程序输出是否符合预期
- 验证类型假注是否正常工作
- 验证各种语法结构是否正确编译执行
