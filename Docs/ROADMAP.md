# Old8Lang 开发路线图

具体待办和验证状态统一维护在 [Todo.md](../changes/Todo.md)；历史执行与测试结果保留在 `archive/Reports/`。

## 方向性重点

1. 优先核实并解决 IL 模式中导致测试进程崩溃、结果错误或生成无效 IL 的问题。
2. 改进三种执行模式的一致性，并按场景检查测试覆盖。
3. 完善语言服务器的作用域、诊断、测试与 VS Code 调试集成。
4. 按测量结果推进虚拟机性能、类型推断及调试工具。

[模式支持矩阵](MODE_SUPPORT.md) 描述各执行模式的支持情况；该矩阵中的历史结论应结合统一待办的复核状态使用。
