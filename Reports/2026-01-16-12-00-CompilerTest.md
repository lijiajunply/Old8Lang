## 测试环境

## 测试内容
验证虚拟机模式下 Lambda 表达式的编译和执行。

### 测试用例: LambdaTest.old8

```old8
func main() {
    PrintLine("Testing Lambda...")
    
    // Define a lambda
    f <- (x:int) -> {
        PrintLine("Inside Lambda: " + x.ToStr())
        return x * 2
    }
    
    // Call the lambda
    result <- f(21)
    PrintLine("Result: " + result.ToStr())
    
    if result == 42 {
        PrintLine("Lambda Test Passed!")
    } else {
        PrintLine("Lambda Test Failed!")
    }
}

main()
```

## 实现细节
1. **Visitor 支持**:
   - 在 `IVisitor` 接口中添加了 `VisitFuncLangValue`。
   - 实现 `BytecodeVisitor.VisitFuncLangValue`，将 Lambda 编译为独立函数并生成 `MakeFunction` 指令。
   - 更新 `BytecodeVisitor.VisitFunctionCallExpression` 支持调用局部变量（`CallDynamic`）。

2. **字节码指令**:
   - 添加 `OpCode.MakeFunction (0x49)`: 创建函数对象。
   - 添加 `OpCode.CallDynamic (0x4A)`: 调用栈顶函数对象。

3. **虚拟机支持**:
   - 在 `VirtualMachine` 中实现了 `MakeFunction` 和 `CallDynamic` 的执行逻辑。

## 遗留问题
- 闭包支持（Closure）目前仅通过 `MakeFunction` 占位，尚未完全支持捕获外部变量（`BytecodeCompiler` 限制）。目前仅支持纯 Lambda。
- `Type Conversion (as)` 仅支持基础类型，复杂类型转换待完善。
