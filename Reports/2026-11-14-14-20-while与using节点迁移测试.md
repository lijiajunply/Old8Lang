# 阶段 2「while / using 节点迁移」测试报告

日期：2026-11-14 14:20
范围：`Docs/architecture-migration/plan.md` §2 的增量：`WhileStatement`、`UsingStatement`
状态：本批完成；阶段 2 整体未完成（解析器、其余循环/声明节点、运行时值仍待拆分）。

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `WhileStatement`、`UsingStatement` | 从 `Old8Lang.Runtime/AST/Statement` 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| Visitor 分派 | `IVisitor` 新增 `VisitWhileStatement`、`VisitUsingStatement`；重新生成后 Runtime 节点 71 |
| 生成器/资源辅助 | `WhileStatement` 的 `RunWithGeneratorContext`/`RunStandard` 与 `UsingStatement` 的同类方法、`DisposeResource` 移入 Runtime 的 `WhileStatementRuntimeExtensions`/`UsingStatementRuntimeExtensions` |
| 生成代码 | 两个旧 `*.Accept.generated.cs` 归档到 `backups/trash-2026-11-14/` |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 25 → 23 |

行为保持：while 的条件求值、break/continue、yield 恢复与性能计数顺序未变；using 的
`/using_block` 执行路径、变量注册与资源释放（ResourceManager / AnyLangValue / IDisposable）
顺序未变；`UsingStatement.DisposeResource` 原为 internal 实例方法，现为扩展类内部实现。
