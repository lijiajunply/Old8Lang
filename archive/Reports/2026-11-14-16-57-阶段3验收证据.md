# 阶段 3 验收证据（后端独立构建、字节码往返、API 迁移）

日期：2026-11-14 16:57  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3 的第 2、3 项目标。

## 1. 后端独立构建

分别构建三个后端项目（均以 `/usr/local/share/dotnet/dotnet`，.NET 10）：

```text
Old8Lang.Interpreter   : 0 个错误
Old8Lang.Compiler      : 0 个错误
Old8Lang.VirtualMachine: 0 个错误
```

每个后端只引用 `Old8Lang.Runtime`；`BackendAssemblyBoundaryTests` 通过程序集元数据验证：
- 三个后端互不引用，也不引用官方模块或 Hosting；
- Runtime 程序集不引用任何后端；
- Runtime 源码不再直接构造三种 Visitor；
- 三个后端都能通过 `RuntimeVisitors` 契约注册并创建，未注册时报错包含组合根指引。

组合根 `Old8HostBuilder` 构造时显式注册解释、IL、VM 三个后端；App、LSP、Benchmarks、Tests
均已更新项目引用。后端注册不再使用 `ModuleInitializer`（避免隐式默认注册与 CA2255），
不经过 Hosting 的宿主必须显式调用对应 `*Backend.Register()`。
