## 执行摘要

本次更新为 Old8Lang 添加了 **7 种新的错误类型**，并创建了 **8 个错误处理测试文件**，全面测试了语言的错误处理机制。新增的错误类型覆盖了常见的运行时错误场景，使 Old8Lang 的错误处理系统更加完善和专业。

## 一、新增错误类型

### 1.1 新增错误类型列表

在 `Old8Lang/Error/AdditionalErrors.cs` 文件中新增了以下 7 种错误类型：

| 错误类型 | 基类 | 用途 | 状态 |
|---------|------|------|------|
| **ValueError** | RuntimeError | 值不在有效范围内或不符合要求 | ✅ 已添加 |
| **AssertionError** | RuntimeError | 断言失败 | ✅ 已添加 |
| **FileNotFoundError** | RuntimeError | 文件不存在 | ✅ 已添加 |
| **RecursionError** | RuntimeError | 递归深度超限 | ✅ 已添加 |
| **NotImplementedError** | RuntimeError | 功能尚未实现 | ✅ 已添加 |
| **PermissionError** | RuntimeError | 权限不足 | ✅ 已添加 |
| **TimeoutError** | RuntimeError | 操作超时 | ✅ 已添加 |

### 1.2 错误类型详细说明

#### ValueError（值错误）

**用途**: 当参数值不在有效范围内或不符合要求时抛出

**构造函数**:
```csharp
// 值超出范围
ValueError(IOldLangTree node, object value, object minValue, object maxValue)

// 值不符合要求
ValueError(IOldLangTree node, object value, string requirement)

// 自定义错误信息
ValueError(IOldLangTree node, string message)
ValueError(SourcePosition position, string message)
```

**使用场景**:
- 数学函数参数验证（如负数的平方根、对数）
- 索引值验证（确保在有效范围内）
- 枚举值验证
- 配置参数验证

#### AssertionError（断言错误）

**用途**: 当断言条件不满足时抛出

**构造函数**:
```csharp
// 带错误信息的断言失败
AssertionError(IOldLangTree node, string message)

// 无错误信息的断言失败
AssertionError(IOldLangTree node)

// 使用位置信息
AssertionError(SourcePosition position, string message)
```

**使用场景**:
- 单元测试断言
- 运行时条件检查
- 不变量验证
- 前置/后置条件检查

#### FileNotFoundError（文件不存在错误）

**用途**: 当文件操作找不到指定文件时抛出

**构造函数**:
```csharp
// 文件不存在
FileNotFoundError(IOldLangTree node, string filePath)
FileNotFoundError(SourcePosition position, string filePath)
```

**使用场景**:
- 文件读取操作
- 导入模块
- 配置文件加载
- 资源文件访问

#### RecursionError（递归深度超限错误）

**用途**: 当递归调用超过最大深度限制时抛出

**构造函数**:
```csharp
// 指定最大深度
RecursionError(IOldLangTree node, int maxDepth)

// 自定义错误信息
RecursionError(IOldLangTree node, string message)
RecursionError(SourcePosition position, int maxDepth)
```

**使用场景**:
- 递归函数调用
- 递归数据结构遍历
- 防止栈溢出
- 无限递归检测

#### NotImplementedError（未实现错误）

**用途**: 当功能尚未实现时抛出

**构造函数**:
```csharp
// 指定未实现的功能
NotImplementedError(IOldLangTree node, string feature)

// 无功能名称
NotImplementedError(IOldLangTree node)

// 使用位置信息
NotImplementedError(SourcePosition position, string feature)
```

**使用场景**:
- 抽象方法的占位符
- 计划中的功能
- 接口实现的占位
- 开发中的功能

#### PermissionError（权限错误）

**用途**: 当没有足够权限执行操作时抛出

**构造函数**:
```csharp
// 指定操作和资源
PermissionError(IOldLangTree node, string operation, string resource)

// 自定义错误信息
PermissionError(IOldLangTree node, string message)
PermissionError(SourcePosition position, string message)
```

**使用场景**:
- 文件系统操作
- 网络访问控制
- 系统资源访问
- 安全策略检查

#### TimeoutError（超时错误）

**用途**: 当操作超时未完成时抛出

**构造函数**:
```csharp
// 指定操作和超时时间
TimeoutError(IOldLangTree node, string operation, int timeoutSeconds)

// 自定义错误信息
TimeoutError(IOldLangTree node, string message)
TimeoutError(SourcePosition position, string message)
```

**使用场景**:
- 网络请求超时
- 数据库查询超时
- 文件 I/O 超时
- 外部进程调用超时

## 四、错误信息格式

Old8Lang 的错误信息格式清晰、结构化，包含以下要素：

### 4.1 错误信息组成

```
[错误代码] 错误描述
位置: 文件名(行:列)
上下文:
  行号 | 源代码
      | ^ 错误发生在这里
建议: 错误修复建议
```

### 4.2 错误信息示例

```
[RUNTIME_ERROR] 索引越界: 索引 5 超出范围 [0, 2]
位置: InterpreterTests/41_index_key_errors.old8(13:15)
上下文:
  11 | printLine("尝试访问索引 5...")
  12 | // 这行应该抛出 IndexError
  13 | element <- arr[5]
     |               ^ 错误发生在这里
建议: 请检查索引值是否在有效范围内
```

### 4.3 颜色编码（ANSI）

- **红色**: 错误代码和错误指示器
- **黄色**: 错误描述
- **蓝色**: 位置信息和行号
- **绿色**: 建议信息

### 5.3 错误处理最佳实践

#### 1. 选择合适的错误类型

```csharp
// ✓ 正确：使用具体的错误类型
if (index < 0 || index >= length)
    throw new IndexError(node, index, length);

// ✗ 错误：使用通用的错误类型
if (index < 0 || index >= length)
    throw new RuntimeError(node, "索引越界");
```

#### 2. 提供清晰的错误信息

```csharp
// ✓ 正确：详细的错误信息
throw new ValueError(node, value, $"必须是正数，但得到 {value}");

// ✗ 错误：模糊的错误信息
throw new ValueError(node, "值错误");
```

#### 3. 包含位置信息

```csharp
// ✓ 正确：使用 AST 节点或位置信息
throw new TypeError(node, "int", actualType);

// ✗ 错误：丢失位置信息
throw new Exception("类型错误");
```

#### 4. 提供有用的建议

```csharp
// ✓ 正确：提供修复建议
throw new FileNotFoundError(node, filePath);
// 自动包含建议："请检查文件路径是否正确，以及文件是否存在"

// ✗ 错误：没有建议
throw new Exception($"文件 {filePath} 不存在");
```
