### 2.1 异常转换层

#### 实现位置
- `Old8Lang/AST/Expression/Value/FuncLangValue.cs` (Lines 59-101)

#### 功能说明
在 Old8LangLib 与 Old8Lang 核心之间添加异常转换层，将 .NET 标准异常自动转换为 Old8Lang 自定义异常。

#### 转换规则
| .NET 异常 | Old8Lang 异常 | 应用场景 |
|----------|--------------|---------|
| `FileNotFoundException` | `FileNotFoundError` | 文件操作失败 |
| `DirectoryNotFoundException` | `FileNotFoundError` | 目录不存在 |
| `ArgumentException` | `ValueError` | 参数验证失败 |

#### 关键代码
```csharp
try
{
    invoke = Method?.Invoke(obj, a);
}
catch (System.Reflection.TargetInvocationException ex) when (ex.InnerException != null)
{
    var innerException = ex.InnerException;

    // FileNotFoundException and DirectoryNotFoundException -> FileNotFoundError
    if (innerException is FileNotFoundException fileEx)
    {
        throw new Error.FileNotFoundError(Position, fileEx.FileName ?? "未知文件");
    }
    if (innerException is DirectoryNotFoundException dirEx)
    {
        throw new Error.FileNotFoundError(Position, dirEx.Message);
    }

    // ArgumentException -> ValueError
    if (innerException is ArgumentException argEx)
    {
        throw new Error.ValueError(Position, argEx.Message);
    }

    throw;
}
```

#### 设计理念
- **Old8LangLib 独立性**: Old8LangLib 使用 .NET 标准异常，不依赖 Old8Lang 核心
- **边界转换**: 在反射调用边界自动转换异常类型
- **一致的用户体验**: 用户始终看到 Old8Lang 异常，不暴露 .NET 实现细节

### 2.3 递归深度限制

#### 实现位置
1. **`Old8Lang/LangParser/VariateManager.cs`** (Lines 47-67) - 深度追踪
2. **`Old8Lang/AST/Expression/Value/FuncLangValue.cs`** (Lines 118-195) - 深度检查

#### 关键参数
- **最大递归深度**: `MaxRecursionDepth = 1000`
- **异常类型**: `RecursionError`

#### 实现机制

**1. 深度追踪（VariateManager.cs）**
```csharp
// 递归深度限制
public const int MaxRecursionDepth = 1000;
private int _recursionDepth = 0;

public int RecursionDepth
{
    get => _recursionDepth;
    set
    {
        if (value > MaxRecursionDepth)
        {
            throw new RecursionError(
                new SourcePosition(0, 0),
                MaxRecursionDepth
            );
        }
        _recursionDepth = value;
    }
}
```

**2. 函数调用时检查（FuncLangValue.cs）**
```csharp
// 调用方法体
// 递归深度检查
variateManagerFunc.RecursionDepth++;
try
{
    variateManagerFunc.AddChildren();
    variateManagerFunc.IsFunc = true;

    // ... 函数执行代码 ...

    return result;
}
finally
{
    // 确保递归深度总是被递减
    variateManagerFunc.RecursionDepth--;
}
```

#### 设计特点
- **Property Setter 验证**: 使用属性 setter 自动验证深度
- **try-finally 保护**: 确保递归深度计数器总是正确递减
- **友好的错误信息**: 提供最大深度信息和解决建议

### 3.1 AssertionError 应用

#### 修改文件
- `Old8Lang/AST/Expression/Value/Instance.cs` (Lines 171-181)

#### 改进内容
将 `Assert()` 函数从抛出泛型 `InvalidOperationError` 改为抛出专门的 `AssertionError`，并提供详细的错误信息。

**修改前**:
```csharp
case "Assert" or "assert":
{
    var value = results[0].Run(manager);
    var value1 = results[1].Run(manager);
    return value.Equal(value1)
        ? new BoolLangValue(true)
        : throw new InvalidOperationError(this, "测试失败");
}
```

**修改后**:
```csharp
case "Assert" or "assert":
{
    var value = results[0].Run(manager);
    var value1 = results[1].Run(manager);
    if (!value.Equal(value1))
    {
        var message = $"断言失败: 期望 {value1}，但得到 {value}";
        throw new Error.AssertionError(this, message);
    }
    return new BoolLangValue(true);
}
```

### 3.2 FileLib 增强

#### 修改文件
- `Old8LangLib/FileLib.cs` (整个文件)

#### 改进内容
所有文件操作函数在执行前都会检查文件/目录是否存在，不存在则抛出 `FileNotFoundException`。

**函数列表**:
- `FileRead(path)` - 读取文件前检查文件存在
- `FileWrite(path, content)` - 写入时检查目录存在
- `FileDelete(path)` - 删除前检查文件存在
- `FileExists(path)` - 原本就是检查函数
- `DirectoryList(path)` - 列出目录前检查目录存在
- `DirectoryCreate(path)` - 创建目录（自动创建父目录）

**示例代码**:
```csharp
public static string FileRead(string path)
{
    if (!File.Exists(path))
    {
        throw new FileNotFoundException($"文件不存在: '{path}'", path);
    }
    return File.ReadAllText(path);
}
```

## 六、架构设计决策

### 6.1 异常分层策略

```
┌─────────────────────────────────────┐
│     Old8Lang 用户代码                │
├─────────────────────────────────────┤
│  Old8Lang 核心 (自定义异常)          │
│  - Old8Exception                    │
│  - RuntimeError                     │
│  - ValueError                       │
│  - FileNotFoundError                │
│  - AssertionError                   │
│  - RecursionError                   │
├─────────────────────────────────────┤
│  ⬆️ 异常转换层 (FuncLangValue.cs)   │
│  - FileNotFoundException → FNFE     │
│  - ArgumentException → ValueError   │
├─────────────────────────────────────┤
│  Old8LangLib (标准 .NET 异常)       │
│  - FileNotFoundException            │
│  - ArgumentException                │
│  - DirectoryNotFoundException       │
└─────────────────────────────────────┘
```

**设计优势**:
1. **库独立性**: Old8LangLib 不依赖 Old8Lang 核心
2. **清晰边界**: 异常转换发生在明确的边界点（反射调用）
3. **一致体验**: 用户始终看到 Old8Lang 风格的错误
4. **易于扩展**: 添加新的转换规则非常简单

### 6.2 递归深度限制设计

**选择 Property Setter 验证的原因**:
- **自动验证**: 每次设置深度时自动检查
- **代码简洁**: 验证逻辑集中在一处
- **不易遗漏**: 不会因为忘记检查而导致栈溢出

**选择 try-finally 的原因**:
- **异常安全**: 即使函数抛出异常，深度也会正确递减
- **资源清理**: 类似于 RAII 模式
- **防止泄漏**: 避免深度计数器永久增加
