# Old8Lang 并发原语原生化实施计划

**创建日期**: 2026-01-03
**状态**: 进行中
**预计工作量**: 大型重构（约 57 个全局函数 + 2 个新语句）

---

## 📋 目标概述

将 `Old8LangLib/AsyncLib.cs` 中的并发原语完全迁移为语言核心的全局函数，并添加配套的 `using` 和 `select` 语句。

### 用户需求确认

- ✅ **集成方式**: 仅全局函数（保持简单）
- ✅ **using 语句**: 仅资源管理（自动 Dispose），**不支持** `using lock`
- ✅ **select 语句**: Channel 多路选择（类似 Go）
- ✅ **AsyncLib 处理**: 完全移除

    ChannelSend(ch, data)
}  // 自动调用 ChannelDispose(ch)

2. **select 轮询策略**: 可能导致 CPU 占用高（需后续优化）

### 兼容性风险
1. **向后兼容性**: 删除 AsyncLib 会破坏使用静态方法的旧代码
   - **解决方案**: 更新所有测试文件和示例代码

### 技术限制
1. **select 编译器模式**: 暂不支持，需后续实现状态机生成
2. **资源类型识别**: using 语句需要准确识别资源类型才能正确 Dispose

## 🎓 学习要点

### BaseGlobalFunction 实现模式

每个全局函数需要实现：

```csharp
public sealed class XxxFunction : BaseGlobalFunction
{
    // 1. 函数名称（支持多个别名）
    public override string[] Names => ["FunctionName"];

    // 2. 参数数量限制
    public override int MinParameterCount => 0;
    public override int MaxParameterCount => 1;

    // 3. 解释器模式执行
    protected override LangValueType ExecuteInternal(
        List<LangExpression> parameters,
        VariateManager manager,
        SourcePosition position)
    {
        // 实现逻辑
    }

    // 4. 编译器模式 IL 生成
    protected override void GenerateIlInternal(
        List<LangExpression> parameters,
        ILGenerator ilGenerator,
        LocalManager local,
        SourcePosition position)
    {
        // IL 生成逻辑
    }

    // 5. 编译器模式返回类型
    protected override Type GetReturnTypeInternal(
        List<LangExpression> parameters,
        LocalManager local)
    {
        return typeof(int); // 或其他类型
    }
}
```

### OldStatement 实现模式

每个语句需要实现：

```csharp
public class XxxStatement : OldStatement
{
    // 1. 解释器执行
    public override void Run(VariateManager manager)
    {
        // 实现逻辑
    }

    // 2. 编译器 IL 生成
    public override void GenerateIl(ILGenerator ilGenerator, LocalManager local)
    {
        // IL 生成逻辑
    }

    // 3. 索引器和 Count
    public override OldStatement? this[int index] { get; }
    public override int Count { get; }

    // 4. 访问者模式
    public override TResult Accept<TResult>(IVisitor<TResult> visitor)
    {
        return visitor.Visit(this);
    }
}
```
