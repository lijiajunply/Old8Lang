# 阶段 3.11 编译器辅助类迁入 IL 后端

日期：2026-11-14 17:30  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3 的 IL 引擎余量。

## 改动

从 `Old8Lang.Runtime/Compiler/` 迁入 `Old8Lang.Compiler/`（命名空间不变）：

- `CompiledDelegateRegistry`（闭包模板注册，仅 IL 后端使用）；
- `CodeGeneration/StaticClassCompiler`（静态类成员调用编译，仅 `DotOperatorILHelper` 使用）；
- `Helpers/CollectionHelper`、`Helpers/ExceptionHelper`、`Helpers/TypeConversion`、
  `Helpers/TaskHelper`（仅 `CompilerVisitor` 与 IL 运算辅助使用）。

保留在 Runtime 的共享编译契约：

- `LocalManager` 及其 `ILGenerationCache`/`CapturedLocal`/`IlIndexHelper`/`StandardLibraryILHelper`；
- `RuntimeGlobals`/`RuntimeGlobalWriter`/`RuntimeConstantRegistry`；
- `AssertHelper`（类型推断使用）与 `ExceptionWrapper`（`ValueTypeToStrMethod` 使用）；
- `Specialization/*`（运行时泛型解析与类型推断使用）。

## 遗留

- `Compiler.cs` 驱动（`Compile`、`GlobalVariableAnalysis`、`ILVerifier`）仍与 Runtime 的
  `AsyncFuncLangValue`/`AsyncStateMachineGenerator` 共享静态标志，需要先把标志拆成
  Runtime 选项类型再迁出。
- 运行时值 partial 与解释期作用域状态同前；阶段 3 不标记完成。
