# Old8Exception 类及其子类优化计划

## 1. 优化目标
- 改进 Old8Exception 类及其子类的错误处理能力
- 实现所有异常类型的标准化错误信息格式
- 增强错误上下文信息，包括错误代码和堆栈跟踪
- 确保所有子类保持适当的继承层次结构
- 为每个异常类型提供特定于其领域的错误信息

## 2. 具体优化方案

### 2.1 改进 Old8Exception 基类
- 统一错误信息格式：确保所有异常类型具有一致的错误信息结构
- 改进堆栈跟踪处理：确保包含完整的调用链并格式化清晰
- 增强错误代码体系：为每种异常类型定义更具体的错误代码
- 优化错误信息格式：
  ```
  [错误代码] 错误消息
  位置：文件名:行号:列号
  上下文：源代码行
         ^ 错误位置
  建议：修复建议
  堆栈跟踪：...
  ```

### 2.2 标准化异常类构造函数
- 为所有异常类提供统一的构造函数重载
- 确保每个构造函数都能正确初始化所有字段
- 简化构造函数参数，减少重复代码

### 2.3 增强错误上下文信息
- 确保所有异常都包含完整的源代码上下文
- 改进堆栈跟踪的格式化，使其更易读

### 2.4 优化子类实现
- 确保所有子类都正确继承基类的字段和方法
- 为每个子类添加特定的错误代码常量
- 确保每个子类的错误信息格式一致
- 添加缺失的构造函数重载

## 3. 实现步骤

1. **修改 Old8Exception 基类**：
   - 改进 `FormatErrorMessage` 方法，实现标准化格式
   - 确保堆栈跟踪信息被正确包含在错误消息中

2. **优化 RuntimeError 及其子类**：
   - 为每个子类添加特定的错误代码常量
   - 统一构造函数参数
   - 确保错误信息格式一致

3. **优化 SyntaxError 类**：
   - 添加特定的错误代码常量
   - 统一构造函数参数
   - 改进错误信息格式

4. **优化 SemanticError 及其子类**：
   - 为每个子类添加特定的错误代码常量
   - 统一构造函数参数
   - 确保错误信息格式一致

5. **测试优化后的异常类**：
   - 运行现有的单元测试
   - 添加新的测试用例，验证标准化错误信息格式
   - 确保所有异常类型都能正确生成和格式化

## 4. 预期效果

- 所有异常类型都具有标准化的错误信息格式
- 错误信息包含完整的上下文信息，便于调试
- 异常类的构造函数更加统一和易用
- 所有子类保持适当的继承层次结构
- 增强的错误处理能力，便于问题定位和解决
