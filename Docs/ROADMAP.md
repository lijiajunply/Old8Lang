# Old8Lang 开发路线图

**最后更新**: 2026年1月17日

本文档提供 Old8Lang 的详细开发计划，包括短期、中期和长期目标。

## 当前状态概览

根据 [MODE_COMPLETION_STATUS.md](./MODE_COMPLETION_STATUS.md) 的分析:

- **解释器模式**: 95% 完成，功能最全面
- **编译器模式**: 75% 完成，缺少泛型和部分高级特性
- **虚拟机模式**: 90% 完成，已实现字节码编译和执行

## 优先级定义

- **P0 (关键)**: 影响核心功能，必须立即解决
- **P1 (高)**: 重要功能，应尽快完成
- **P2 (中)**: 增强功能，按计划完成
- **P3 (低)**: 优化和改进，可延后

## 短期计划 (1-2 个月)

### 1. 编译器模式功能补全 (P1)

**目标**: 将编译器模式完成度从 75% 提升到 90%

#### 1.1 泛型支持 (P1)

**当前状态**: 编译器模式已实现基本泛型支持（包括函数、类、继承和约束）

**任务**:
- [x] 实现编译器的泛型函数支持
  - 泛型参数解析
  - 类型参数实例化
  - 泛型约束检查
- [x] 实现编译器的泛型类支持
  - 泛型类定义
  - 泛型类实例化
  - 泛型类继承
- [x] 添加泛型相关测试 (至少 10 个测试用例)
- [x] 更新文档和示例

**预期成果**: 编译器模式支持完整的泛型功能

#### 1.2 运算符重载支持 (P2)

**当前状态**: 三种模式都支持运算符重载

**任务**:
- [x] 实现编译器的运算符重载支持
  - 算术运算符重载 (`_add`, `_sub`, `_mul`, `_div`, `_mod`, `_pow`)
  - 比较运算符重载 (`_eq`, `_lt`, `_gt`, `_le`, `_ge`)
  - 索引运算符重载 (`_getitem`, `_setitem`)
- [x] 实现虚拟机的运算符重载支持
- [x] 添加运算符重载测试
- [x] 更新文档

**预期成果**: 三种模式都支持运算符重载

#### 1.3 异步功能完善 (P1)

**当前状态**: 编译器模式异步支持不完整 (60%)

**任务**:
- [ ] 完善编译器的 async/await 支持
  - 异步函数编译
  - await 表达式处理
  - 异步状态机生成
- [ ] 完善异步生成器支持
- [ ] 完善 Task API 支持
- [ ] 添加异步相关测试 (至少 15 个测试用例)

## 风险和挑战

### 技术风险

1. **泛型实现复杂度**: 编译器模式的泛型实现可能比预期复杂
2. **性能优化难度**: JIT 编译和高级优化需要大量工作
3. **跨平台兼容性**: 不同平台的兼容性问题

### 缓解措施

1. **分阶段实现**: 将复杂功能分解为小步骤
2. **充分测试**: 每个功能都要有完整的测试
3. **社区反馈**: 及时收集和响应社区反馈
