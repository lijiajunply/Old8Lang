# 阶段 2「语法模型与解析器拆分」完成测试报告

日期：2026-11-14 15:52

状态：**阶段 2 完成**（语法/解析项目可独立构建、不引用执行后端；回归与基线一致）。

## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `LangParser` 整体迁移 | `Old8Lang.Runtime/LangParser`（22 个文件）迁入 `Old8Lang.Syntax/LangParser`；命名空间 `Old8Lang.LangParser` 不变 |
| `ScopeLayer` | 解释器作用域类从 LangParser 移回 `Old8Lang.Runtime/Interpreter` |
| 解析器解耦 | 删除解析器中最后的 `Instance`、`LangListItem`、`NestedIndexAccess`、`NestedSliceAccess` 类型分支；切片/索引只处理 Syntax 节点 |
| 程序集门禁 | 新增 `SyntaxParserBoundaryTests`（2 项）：解析器类型属于 Syntax、Syntax 仅引用 Core、Syntax 源码不出现执行后端类型 |
| IL 修正 | `CompilerVisitor.EmitOperationOutputType` 在标准库模块解析前先归一化 `CallExpression`，修复 `import Time` + `Thread.Sleep` 的模块调用路径 |

## 2. 阶段 2 门禁证据

```text
dotnet build Old8Lang.sln                    # 0 错误
dotnet build Old8Lang.Syntax/Old8Lang.Syntax.csproj  # 独立构建 0 错误
```

- `Old8Lang.Syntax.csproj` 仅引用 `Old8Lang.Core`（`ArchitectureProjectDependencyTests` 固化）。
- 解析器与全部语法节点位于 `Old8Lang.Syntax`；Syntax 源码无 `using Old8Lang.Interpreter/Compiler/
  Bytecode/ModuleSystem/TypeSystem/...`，也无 `VariateManager`/`ILGenerator`/`LocalManager`/`UnifiedModule`
  标识符（`SyntaxParserBoundaryTests.SyntaxSources_DoNotReferenceExecutionBackends`）。
- 运行时值通过 Runtime 工厂/扩展按语法节点缓存（`FunctionSyntaxRuntimeFactory`、
  `ClassSyntaxRuntimeFactory`、`CallSyntaxAdapter`、`LinqExpressionRuntimeExtensions` 等）适配，
  Syntax 不反向引用 Runtime。
- 生成器仍扫描 `Old8Lang.Runtime/AST` 的运行时值节点（`visitor-codegen.json` 无需改动），
  语法节点手工实现 `Accept`。
