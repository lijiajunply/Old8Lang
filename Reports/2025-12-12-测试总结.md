## 测试示例

### 示例 1: AssertionError
```old8
Assert(5, 10)  // 期望 10，但得到 5
```
**结果**: `Old8Lang.Error.AssertionError: 断言失败: 期望 10，但得到 5` ✅

### 示例 2: FileNotFoundError 转换
```old8
import File
FileRead("/nonexistent/file.txt")
```
**结果**: `Old8Lang.Error.FileNotFoundError: 文件不存在: '/nonexistent/file.txt'` ✅

### 示例 3: ValueError 转换
```old8
import MathLib
Factorial(-1)  // 参数必须是非负整数
```
**结果**: `Old8Lang.Error.ValueError: 阶乘函数的参数必须是非负整数` ✅

### 示例 4: RecursionError
```old8
infiniteRecursion(n) -> {
    infiniteRecursion(n + 1)
}
infiniteRecursion(1)
```
**结果**: 在深度 1001 时抛出 `Old8Lang.Error.RecursionError` ✅

## 已知问题

### ⚠️ MathLib 返回值类型转换
- **问题**: 函数返回 `Null` 而非实际计算结果
- **影响**: 不影响异常转换功能，但数值计算结果不可用
- **原因**: .NET 基本类型到 Old8Lang 值类型的转换需要改进
- **优先级**: 高

**示例**:
```old8
result <- Factorial(5)
printLine(result.toString())  // 输出: Null（预期: 120）
```
