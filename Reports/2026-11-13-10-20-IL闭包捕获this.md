# IL 闭包捕获 this 测试

测试日期：2026-11-13

## 修复范围

类实例方法创建 lambda 时，当前实例会作为闭包值保存。lambda 模板中的 `this` 从闭包槽位读取；对尚未完成的动态类字段访问改为运行期反射读写，避免 `DynamicMethod` 引用 `TypeBuilder`/`FieldBuilder` 产生无效 IL。

## 回归用例

既有 `ClosureCapturingThis_CompilesAndExecutesCorrectly` 覆盖：

```old8
class Counter {
    private count

    func init() { this.count <- 0 }
    func createIncrementer() -> function {
        return () -> {
            this.count <- this.count + 1
            return this.count
        }
    }
    func getCount() -> int { return this.count }
}

counter <- Counter()
incrementer <- counter.createIncrementer()
Assert.Equal(1, incrementer())
Assert.Equal(2, incrementer())
Assert.Equal(2, counter.getCount())
```
