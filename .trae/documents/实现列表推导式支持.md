# 实现列表推导式支持

## 1. 概述

我将实现对Old8Lang语言的列表推导式支持，包括基本列表推导式、带条件筛选的列表推导式、带if-else条件的列表推导式以及嵌套列表推导式。

## 2. 实现步骤

### 2.1 修改语法解析器

在`ParseArrayOrRange`方法中添加列表推导式的支持，识别并解析以下语法：
- 基本列表推导式：`[x * x for x in numbers]`
- 带条件筛选的列表推导式：`[x for x in numbers if x % 2 == 0]`
- 带if-else条件的列表推导式：`[x if x % 2 == 0 else 0 for x in numbers]`
- 嵌套列表推导式：`[x + y for x in [1, 2, 3] for y in [4, 5]]`

### 2.2 实现AST节点

创建新的AST节点类`ListComprehension`，用于表示列表推导式，包含以下属性：
- 表达式部分：用于生成列表元素的表达式
- 变量部分：遍历变量名
- 可迭代对象部分：被遍历的对象
- 条件部分：可选的筛选条件
- 嵌套的for循环部分：支持多重循环

### 2.3 实现解释执行逻辑

在`ListComprehension`类中实现`Run`方法，执行列表推导式的逻辑：
1. 遍历可迭代对象
2. 为每个元素设置变量值
3. 检查条件（如果有）
4. 计算表达式值
5. 将结果添加到结果列表中

### 4.3 解释执行

```csharp
public override LangValueType Run(VariateManager manager)
{
    // 执行可迭代对象
    var iterableValue = Iterable.Run(manager);
    
    // 创建结果列表
    var result = new List<LangValueType>();
    
    // 遍历可迭代对象
    foreach (var item in iterableValue.GetItems())
    {
        // 设置变量值
        manager.Set(Variable, item);
        
        // 检查条件（如果有）
        if (Condition == null || Condition.Run(manager) is BoolLangValue boolValue && boolValue.Value)
        {
            // 计算表达式值
            var exprValue = Expression.Run(manager);
            result.Add(exprValue);
        }
    }
    
    // 返回结果列表
    return new ListLangValue(result, Position);
}
```
