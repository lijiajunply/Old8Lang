# 实现语法测试函数计划

## 1. 需求分析
- 编写专门的语法测试函数，只负责语法解析步骤
- 使用BlockStatement的ToCode方法输出解析结果
- 让Old8Lang.App支持调用这个语法测试函数

在`Program.cs`中添加处理`-s`参数的逻辑：
- 验证输入文件扩展名

- 调用`BlockStatement.ToCode()`方法输出解析结果

- 函数名为`SyntaxTest`
- 接收文件路径作为参数
- 返回解析后的代码字符串
- 处理解析过程中的异常

private static string SyntaxTest(string filePath)

}
