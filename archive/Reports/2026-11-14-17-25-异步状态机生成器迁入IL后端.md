# 阶段 3.14 异步状态机生成器迁入 IL 后端

日期：2026-11-14 17:25  
范围：[plan.md](../Docs/architecture-migration/plan.md) 阶段 3 的 IL 引擎余量。

## 改动

1. Runtime 新增 `IAsyncStateMachineGenerator` 契约（`Old8Lang.AsyncGeneration`）：
   - `DefineVariable`、`LoadVariable`、`StoreVariable`、`EmitReturn`；
   - `GetStateIndex`、`EmitAwaitYield`、`EmitAwaitResume`。
2. `LocalManager.AsyncStateMachineGenerator` 由具体类型改为接口；`LocalManager` 的三个变量读写
   路径通过接口调用。
3. `AsyncStateMachineGenerator` 从 Runtime 迁入 `Old8Lang.Compiler/AsyncGeneration/`，命名空间不变，
   并实现接口。
4. Runtime 的 `AwaitExpressionCompilerExtensions` 与 `ForIn`/`AsyncForIn` 的 `.Compiler` 扩展
   只依赖接口；`AsyncFuncLangValue` 的 IL 扩展与 `Compiler` 驱动继续使用具体生成器。
5. Runtime 的 `AsyncGeneration/` 现在只剩解释器生成器（`GeneratorAstScanner`、
   `GeneratorExecutionContext`、`GeneratorStateMachine`、`GeneratorStateMachineBuilder`）与共享接口。
