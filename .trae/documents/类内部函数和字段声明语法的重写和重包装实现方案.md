# 实现类成员的访问修饰符支持

## 1. 目标

扩展 Old8Lang 的类成员声明语法，支持访问修饰符（public、private、static），通过包装 ID 类型实现，同时保持向后兼容性。

## 2. 实现步骤

### 2.1 更新词法分析器

- 在 `LangTokenType.cs` 中添加 `Public` 和 `Private` 关键字枚举
- 更新 `KeywordType` 字典，添加 public 和 private 关键字映射

### 2.2 修改解析器支持修饰符

- 在 `LangParser.cs` 中添加 `ParseAccessModifiers` 方法，用于解析访问修饰符
- 修改 `ParseClassBlock` 方法，使用责任链模式处理成员声明
- 更新 `ParseFuncDeclaration` 方法，使其能够处理带有修饰符的函数声明
- 更新 `ParseSetStatement` 方法，使其能够处理带有修饰符的字段声明

### 2.3 更新 AST 结构

- 修改 `SetStatement` 类，使其支持 `ClassMemberId`
- 修改 `FuncInit` 类，使其支持 `ClassMemberId`
- 更新 `BlockStatement` 中的 `ToAnyData` 和 `ToStaticData` 方法，使用 `ClassMemberId` 替代 `LangId`

### 2.4 运行时支持

- 更新 `VariateManager` 以支持访问修饰符检查
- 修改 `TypeTemplate` 以处理带有修饰符的静态和实例成员
- 确保 `AnyLangValue` 正确处理带有修饰符的成员访问

### 2.5 更新测试

- 创建测试用例验证访问修饰符功能
- 确保现有测试仍然通过

## 3. 实现细节

### 3.1 解析器修改

- 使用责任链模式处理类成员声明，支持多种修饰符组合
- 修饰符解析结果转换为 `ClassMemberId` 对象
- 保持与现有语法的向后兼容性

### 3.2 成员存储结构

- 在 `BlockStatement` 中使用 `ClassMemberId` 存储成员
- 区分实例成员和静态成员
- 支持基于修饰符的访问控制

### 3.3 运行时行为

- 静态成员通过类名访问
- 私有成员仅在类内部可见
- 公共成员可以在任何地方访问

## 4. 预期效果

```old8
class A {
    static public a <- 1
    private b <- 2
    public func c() {
        return b
    }
}

PrintLine(A.a) // 输出: 1
var obj = A()
PrintLine(obj.c()) // 输出: 2
PrintLine(obj.b) // 错误: 无法访问私有成员
```

## 5. 向后兼容性

- 现有代码无需修改即可正常运行
- 新语法与旧语法兼容
- 支持逐步迁移到新语法
