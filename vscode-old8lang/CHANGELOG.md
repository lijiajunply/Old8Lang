# 更新日志

## [0.2.0] - 2026-01-02

### 新增功能
- **查找引用**：支持查找符号的所有引用位置（Shift+F12）
  - 可以选择是否包含定义位置
  - 支持函数、类、变量的引用查找
- **重命名符号**：支持重命名符号并自动更新所有引用（F2）
  - 支持函数重命名
  - 支持类重命名
  - 支持变量重命名
  - 自动更新所有引用位置

### 改进
- 改进悬停提示的文档注释显示
- 优化符号查找性能

### 已知限制
- 不支持跨文件查找引用和重命名
- 类成员（属性、方法）暂不支持查找引用和重命名

## [0.1.0] - 2025-12-XX

### 初始发布
- 语法高亮支持
- 智能补全（关键字和符号）
- 跳转到定义（F12）
- 悬停提示
- 基础的错误诊断
- Language Server 集成
