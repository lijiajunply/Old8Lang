## 1. 本批改动

| 变化 | 说明 |
|------|------|
| `EnumInit`、`SelectStatement` | 从 Runtime 迁入 `Old8Lang.Syntax/AST/Statements`，命名空间不变 |
| Visitor 分派 | `IVisitor` 新增 `VisitEnumInit`、`VisitSelectStatement`；重新生成后 Runtime 节点 63 |
| 执行辅助 | Select 的通道轮询、生成器路径与 `ChannelClosedError` 逻辑移入 `SelectStatementRuntimeExtensions` |
| 可见性调整 | Visitor 改用 `EnumInit.EnumName`/`Members` 公开属性（原内部字段不再跨程序集访问） |
| 生成代码 | 两个旧 `*.Accept.generated.cs` 归档到 `backups/trash-2026-11-14/` |
| 测试 | 语法程序集归属与 `SyntaxOnlyVisitor` 桩补全；遗留 partial 基线 18 → 17 |

行为保持：枚举成员求值、重复名检查、类型注册与 IL 类变量创建；select 的非阻塞收发、
default 立即执行、全关闭异常与 1ms 轮询休眠顺序均未改动。
