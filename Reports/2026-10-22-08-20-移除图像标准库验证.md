# 移除图像标准库验证（2026-10-22）

**范围**：删除 `Image` 标准库（图片读写/缩放/裁剪/旋转/翻转/滤镜/绘制）及其全部关联代码，
并验证编译、三种执行模式与单元测试基线无新增失败。

## 1. 改动清单

| 文件 | 改动 |
|------|------|
| `Old8LangLib/ImageLib.cs` | 删除（1304 行，基于 SkiaSharp 的 `ImageLib`） |
| `Old8LangLib/Old8LangLib.csproj` | 移除 `SkiaSharp` 包引用（该文件是唯一使用者） |
| `Old8Lang/StandardLibrary/StandardLibraryRegistry.cs` | 移除 `["Image"]` 模块注册 |
| `Old8Lang.LanguageServer/Services/NativeLibraryRegistry.cs` | 移除 6 个图片函数名（补全用） |
| `Old8Lang.LanguageServer/Handlers/DocumentLinkHandler.cs` | 移除 `["Image"] = "ImageLib.cs"` 文档链接映射 |
| `Docs/CHANGELOG.md` | 在 2026-10 的 API 分组补一条「移除 `Image` 标准库」 |

删除后全仓库（排除 bin/obj/TestResults）已无 `ImageLib` / `SkiaSharp` / `SKBitmap` / 图片函数名残留，
仅 CHANGELOG 的新增说明里出现 `import "Image"` 字样。

## 2. 编译

```bash
dotnet build Old8Lang.sln
```

结果：**0 个错误**，568 个警告（与改动前一致的既有警告）。

## 3. 运行验证

### 3.1 `import "Image"` 已不可用（预期行为）

`/tmp/o8-imgcheck/import_image.old8`：

```old8
import "Image"
PrintLine("ok")
```

```bash
dotnet Old8Lang.App/bin/Debug/net10.0/Old8Lang.App.dll -f import_image.old8
```

输出：`[IMPORT_ERROR] 无法导入模块 'Image'`，解析步骤显示「不是标准库」，退出码 1。
符合「模块已移除」的预期。

### 3.2 其它标准库不受影响（解释模式）

`/tmp/o8-imgcheck/import_math.old8`：

```old8
import "Math"
PrintLine(Math.Sqrt(9))
```

`-f` 输出 `3`，退出码 0。

### 3.3 既有问题：IL / VM 下标准库 `import` 不可用

同一脚本三种模式对比：

| 模式 | 结果 |
|------|------|
| `-f`（解释） | ✅ 输出 `3` |
| `-il` | ❌ `[NAME_ERROR] 名称 'Math' 未定义`（2:11） |
| `-vm` | ❌ `[IMPORT_ERROR] 加载模块 'Math' 失败: 无法读取模块文件 'Math'` |

**与本次改动无关**：在 `HEAD`（`523b6074`，未含本次改动）的独立 worktree 上构建后复跑，
`-il` / `-vm` 报同样的错误。已记录到 `Todo.md`，未顺手修改。
